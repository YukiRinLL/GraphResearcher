在上一章的分类基础上，端到端 VLA、分层大模型（LLM/VLM+skill APIs）、层级 LLM+RL 和世界模型辅助路线共同构成当前具身智能的几条主干技术路径。尽管具体模型和系统名称在不同文献中不尽相同，但中国信通院具身智能发展报告及《基于大模型的具身智能系统综述》等材料在多处指出，这几条路线在数据需求、任务表现、泛化与工程复杂度上的差异已经较为清晰。[5][6]

（一）数据规模与质量需求的差异

从数据驱动视角看，几条路线对数据的依赖呈现不同特征。具身智能发展报告将端到端 VLA 路线视为高度依赖闭环具身数据的方案：例如 Google Robotics 的 RT‑1 通过在家庭厨房场景采集大量真实操作数据，训练出能够执行700余种任务的模型，并在约3000次测试中取得平均约97%的成功率。[7] 这展示了在单一平台和限定场景下，端到端路线可以通过聚焦数据采集实现高性能，但也意味着其泛化能力高度受限于数据覆盖的任务和环境分布。[7]

世界模型辅助和数据金字塔路线则从理论和实证层面揭示了数据需求的幂律特征。中国信通院报告引用 ManiBox 等工作指出，空间泛化所需数据量与空间体积呈幂律关系：例如要在约38倍更大的空间范围内实现泛化，数据量需要扩展大约38^0.35倍；在特定设置下，每增加约10倍训练数据，模型性能可大致按比例提升。[6] 报告由此将高质量、超大规模具身数据视为具身基础模型的核心支撑资源，并强调无论是端到端 VLA、分层大模型还是层级 LLM+RL 路线，如果想在更大任务空间和更多本体上实现泛化，都必须遵守这一“数据金字塔”逻辑。[5][6]

相比之下，分层大模型和层级 LLM+RL 路线在一定程度上可以通过“以语言知识和通用视觉模型补数据”的方式缓解纯具身数据需求，但综述指出，大脑层通用具身基础模型截至2025年仍主要停留在实验室研发阶段，在具身场景专用数据规模和质量、训练方法以及语言模型在物理推理和工具使用方面的固有缺陷上存在关键短板。[5] 因此，从数据侧看，端到端 VLA 的优势在于一旦获得足量高质量闭环数据，即可在特定平台显著提升表现；分层大模型和层级 LLM+RL 的优势在于可以复用通用语义和视觉预训练知识以减少专用数据压力；世界模型辅助路线则通过仿真和生成建模在理论上放大数据采样能力，但受限于 sim2real 以及仿真逼真度问题。[6][5]

（二）短程/长程任务表现对比

在任务时长与复杂度维度，端到端 VLA 与分层路线的差异更加明显。具身智能发展报告在评估端到端 VLA 时指出，目前代表性系统尚未形成稳定的“感知–决策–执行”闭环，在跨环境和跨本体的长程任务上，系统成功率多在20%–40%区间。[6] 报告以整理垃圾、物品交换等家庭长程任务为例，指出即便结合分层 Gemini Robotics‑ER 1.5 与 Gemini Robotics 的 VLA 模型，整体系统在多步骤任务上的成功率仍然受限。[6] 相比之下，在短程、结构化的厨房操作任务上，RT‑1 这类端到端模型可以在约700个任务上达到接近97%的成功率，说明端到端路线在短程、场景受控的任务上具有较强优势。[7]

分层大模型（LLM/VLM+skill APIs）以及层级 LLM+RL 路线则通过显式任务分解和多时间尺度控制来提升长程任务能力。产业综述以 Hi‑Core 等架构为例，描述其通过上层大语言模型设高层策略、下层强化学习生成低层动作，实现两层控制。[8] 报告同时强调，多时间尺度分层控制在具身智能系统中是一条重要技术路径：高层任务规划和决策通常在1–10 Hz 的低频率运行，而低层本体控制需要≥100 Hz 的高频环路。[6] 这种结构使得系统在处理长程、多步骤任务时可以保持策略一致性和局部纠错能力，但也带来工程复杂度的提升。

世界模型辅助路线在长程任务表现上更多依赖“在世界模型中规划，再在真实环境执行”的思路。具身智能发展报告指出，通过在仿真环境中训练政策并利用世界模型进行长程规划，可以在一定程度上提升复杂任务中的策略稳定性和探索效率，但当前 sim2real gap 和世界模型逼真度仍限制了这一路线在真实复杂环境中的表现。[6] 综合来看，端到端 VLA 路线在短程、局部任务表现突出，分层大模型和层级 LLM+RL 在长程任务和多步骤策略上更具结构优势，世界模型辅助路线则从规划和仿真侧提供潜在增益，但尚处于探索阶段。[5][6][8]

（三）跨场景与跨本体泛化能力

在泛化维度，中国信通院报告对端到端 VLA 路线给出了较为审慎的评价：现有 VLA 模型性能表现与本体强相关，在跨本体迁移时很难复现模型性能；在跨场景泛化方面也存在明显局限。[6] 即便是 RT‑1 这类在目标平台和场景内表现优异的系统，[7] 在迁移到不同形态或显著不同任务空间时仍面临数据分布和平台差异的挑战。

相比之下，分层大模型路线通过将任务理解和技能编排抽象为语言与 API 层，在理论上更有利于跨场景迁移：高层任务描述可以保持相对稳定，底层技能库和本体适配可以按场景进行扩展或替换。[5][6] 层级 LLM+RL 路线则在高层策略与低层动作之间引入明晰的接口，使得在迁移到新场景或本体时，可以局部替换 RL 策略或控制器，而保留高层任务理解能力。[8] 不过综述指出，大脑层具身基础模型在跨场景和跨本体物理推理能力上仍然不足，这是所有以大模型为“脑”的路线共同面临的问题。[5]

世界模型辅助及数据金字塔路线在泛化能力上从数据和模型结构两侧提供支持：幂律数据分析表明，随着空间体积放大，若保持泛化水平不变，数据规模需按幂律扩展，这为跨场景泛化提供了量化约束。[6] 同时，世界模型的显式结构可以帮助策略在虚拟环境中体验更多场景变化，从而提升泛化潜力。但报告也提醒，世界模型的偏差和训练数据的覆盖度直接影响泛化效果，sim2real gap 仍是关键瓶颈。[6]

（四）控制频率、实时性与软硬协同复杂度

多份报告在讨论具身智能控制路线时，都强调了“多时间尺度控制”与软硬协同的难度。具身智能发展报告给出定量示例：针对高层次任务规划和决策，处理频率大概在1–10 Hz，而针对低层次本体控制频率需至少在100 Hz以上。[6] 在端到端 VLA 路线中，一般由单一大模型或数个联结的模型覆盖从感知到动作的全过程，在软硬协同上需要同时满足慢速高层策略与高速低层控制的需求，这显著增加了工程复杂度，尤其是在安全和稳定性要求高的场景。[6][5]

分层大模型与层级 LLM+RL 路线通过明确分拆高低层模块来缓解这一问题：高层通用大模型主要在较低频率上运行，负责指令、规划和策略选择，低层控制器或 RL 模块则在高频环路中执行动作，从而使得软硬接口更加清晰。[6][8] 不过，这也要求系统在模块间设计可靠的接口协议和故障隔离机制，防止高层模型的误判通过低层环路放大为危险动作。[5] 世界模型辅助路线在控制频率上可以通过在仿真环境中进行大规模离线训练，然后在真实系统中只部署经过验证的策略，从而部分降低在线实时推理压力，但最终系统仍需满足上述多时间尺度控制要求。[6]

综合而言，端到端 VLA 路线在工程上追求极简的模块数量，但在软硬协同和实时控制方面承受较大压力；分层大模型和层级 LLM+RL 路线在控制频率和接口设计上更符合传统工程实践，但需要解决跨模块协调与全局稳定性问题；世界模型辅助路线则以仿真和离线规划为重点，在实时控制环节中依赖既有控制架构。[5][6][8]

（五）综合评价与适用场景

基于上述比较，中国信通院及相关综述给出的阶段性判断是：截至2025年初，通用具身智能商业化，无论采用端到端 VLA 还是分层“大模型＋控制器”方案，均普遍面临“感知–规划–控制–执行”闭环算法尚不成熟以及高质量具身数据严重匮乏的挑战，这对各条路线的工程化落地形成共性约束。[5][6] 在此基础上，可以做出相对谨慎的路线适用性分析：

在数据相对可控、任务边界清晰且安全风险较低的场景（如受限家务、简单搬运和结构化操作），端到端 VLA 路线凭借其一体化控制和较高短程任务成功率，具有一定试点优势，但跨场景和跨本体扩展仍需显著的再训练和数据采集。[7][6] 在需要长程、多步骤任务规划且安全要求高的工业或服务机器人场景，分层大模型和层级 LLM+RL 路线更符合当前工程实践，通过显式规划和多时间尺度控制提升系统可解释性和稳定性，但也需要更复杂的系统集成和测试流程。[5][6][8]

对于希望在大规模、多场景环境中部署具身基础模型的团队，世界模型辅助和数据金字塔路线提供了方法论支撑，强调通过世界模型和仿真平台进行数据放大和策略预训练，但受限于 sim2real gap 和世界模型精度，这一路线短期内更适合作为其他路线的训练基础设施，而非直接的部署架构。[6] 在所有路线之上，高质量具身数据与“大脑–小脑–本体”技术栈的协同仍是决定通用具身智能能否从“实验室阶段”走向规模应用的核心因素。[5][6]

总体来看，当前具身智能尚处于大模型驱动的新拐点期，端到端、大模型中心、分层控制和世界模型辅助路线仍在并行探索阶段。学术综述倾向按算法与学习范式区分 modular pipeline、LLM for planning、policy learning from demonstration、world‑model‑based control 等标签，而产业与政策报告则侧重“大模型＋机器人”“端到端 VLA”“层级 LLM+RL”“世界模型”“复合多态机器人”等术语，两种视角在路线划分上的重合部分，构成了未来数年具身智能技术演进的主要轨道。[5][6][8]
