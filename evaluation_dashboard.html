DeepResearch Agent Evaluation

GraphResearcher 评测与验证平台

这个页面直接面向真实运行产物工作。它把记忆图谱、规划与搜索轨迹、写作提交过程、 收敛判定和缺陷诊断放进同一个 HTML 视图里，用于检查一次 DeepResearch run 到底回答了什么、漏了什么、为什么停下。
