在2022–2025年的学术综述和产业报告中，具身智能技术路线已形成相对清晰的多路并行格局。中国信通院具身智能发展报告以及《基于大模型的具身智能系统综述》等文献，将当前通用具身智能系统抽象为“大脑–小脑–本体”技术栈，并据此区分控制/算法侧、大模型“脑”侧、数据侧与本体/形态侧的不同技术路径。[5][6] 下文将依据这些资料，对主要路线进行分类与简要特征说明。

一、模块化分层控制路线

传统机器人领域长期以“感知–规划–控制–执行”的模块化分层架构为主流，具身智能阶段的许多系统仍在这一框架上演化。行业报告指出，多时间尺度分层控制是具身智能系统的技术刚需：高层任务规划和决策通常在约1–10 Hz 频率运行，而低层本体控制环路需要至少100 Hz 甚至更高的频率，以保证稳定和安全。[6] 在这一路线中，感知模块（可包含 SLAM、视觉识别等）与规划模块（路径规划、任务分解）保持相对独立，由运动控制器（如 MPC、WBC 等）在高频环路输出具体扭矩或速度指令。

中国信通院报告明确提到，以大模型驱动的具身智能并未完全替代传统控制，而是在“通用大模型＋控制器”的组合中保留了模块化分层：大语言模型或规划模块负责高层策略，传统控制器或强化学习策略负责低层动作，这种“LLM 设高层策略＋控制器/ RL 生成底层动作”的分工，实质上属于模块化分层控制的扩展版本。[6][8] 因此，模块化分层路线可以理解为以经典控制和分层架构为骨干，逐步吸纳大模型和学习算法，但在工程实现上仍强调清晰的接口与安全冗余，适合对实时性和可靠性要求极高的工业和移动机器人场景。[6]

二、分层大模型（LLM/VLM+skill APIs）路线

基于大模型的具身智能系统综述将“大模型中心”视为一条独立技术路线，其典型形态是以大语言模型、大型视觉模型或多模态基础模型作为“大脑”，通过代码生成、技能调度和 API 调用实现高层任务规划与技能编排。[5] 报告描述的技术演进路径是：从传统基于模型和基于学习的运动控制阶段，发展到“通用大模型＋机器人”阶段，其中大语言模型用于任务理解与代码生成，视觉语言模型用于环境语义理解，视觉语言动作（VLA）模型用于端到端动作策略生成。[5][6]

在分层大模型路线中，LLM/VLM 通常不直接输出关节级指令，而是通过 skill APIs 或中间 DSL 调用一组预定义或学习得到的技能库。例如，产业综述中将“LLM for planning”“policy learning from demonstration”“world‑model‑based control”等关键词归入这一类路线，强调其特点是利用基础模型承担通用认知与符号规划，再由下游策略或控制模块执行具体动作。[5][6] 中国信通院报告也指出，许多具身智能系统采用“高层通用大模型＋低层传统控制或 RL”的结构，在技术栈上表现为“大脑”侧的大模型与“小脑”侧的控制模块解耦。[6] 这一路线的优势在于任务理解和跨任务迁移能力较强，工程上可以通过 API 封装将技能库不断扩展，但其瓶颈在于：具身基础模型仍主要停留在实验室研发阶段，在数据规模与质量、训练方法以及物理推理和工具使用能力方面存在明显不足，影响了整体闭环性能。[5]

三、端到端 VLA 路线

端到端视觉–语言–动作（Vision‑Language‑Action, VLA）模型是近年具身智能最受关注的路线之一。行业报告将 Google Robotics 的 RT‑1 视为端到端 Transformer 控制路线的代表：RT‑1 能在家庭厨房场景执行700余种具体任务，在约3000次真实测试中平均成功率约97%，显示出较强语义泛化和任务扩展能力。[7] 这一类系统通常以多模态传感输入（图像、文本指令等）直接映射到动作序列，弱化显式规划模块，从而在特定平台与场景内实现“指令到动作”的一体化控制。[7]

然而，中国信通院发展报告与综述普遍强调，端到端 VLA 路线当前存在若干结构性局限：一是泛化性有限，模型性能与具体机器人本体强相关，跨本体迁移时难以复现原有性能；二是长程任务执行能力不足，在“整理垃圾”“物品交换”等家庭长程任务上，结合分层 Gemini Robotics‑ER 1.5 与 Gemini Robotics VLA 模型的系统成功率多在约20%–40%；三是软硬协同难，高层规划和决策处理频率约在1–10 Hz，而低层本体控制频率需至少100 Hz，这种时间尺度差异显著增加了端到端方案在真实系统中的工程复杂度。[6][5] 因此，端到端 VLA 路线在受控环境和特定平台下已展示出高性能样板，但在通用真实环境、大规模多本体部署和安全可控要求下仍处于探索阶段。[6][7]

四、层级 LLM+RL 路线

另一条被频繁提及的路线是层级 LLM+RL 控制。产业综述以 Hi‑Core 结构为代表，指出其强化学习部分分两层：上层由大语言模型设高层策略，下层由强化学习生成低层动作。[8] 行业报告进一步将这一架构概括为“LLM 指挥高层任务规划＋RL 在高频环路生成具体控制”，并强调在具身智能控制路线中，多时间尺度分层控制是一条重要技术路径：高层策略模块工作在1–10 Hz 的低频，高频控制环路则由 RL 或经典控制器在≥100 Hz 的频率下执行动作。[6][8]

从“大脑–小脑–本体”视角看，层级 LLM+RL 路线的“大脑”侧由通用大模型承担任务理解和分解，“小脑”侧则由 RL 或混合控制器承担具体动作生成，本体侧仍依赖成熟的机电结构。[5] 与端到端 VLA 相比，这一路线更强调显式规划与多层次控制，在长程、多步骤任务上具备潜在优势；但其工程复杂度较高，需要同时解决 LLM 提示工程、RL 策略稳定性以及软硬协同的接口设计问题。[6][8] 现阶段公开资料更多是原型系统和实验性架构，尚未形成统一的工业标准，但在学术与产业调查中已被明确标注为具身智能的一条重要技术路径。[5][8]

五、世界模型辅助路线

世界模型辅助路线以显式构建环境动态或任务世界模型为特征，在具身智能基础模型研究中被视为重要方法论。中国信通院报告引用 ManiBox 和 GEN‑0 等工作指出，空间泛化所需数据量与空间体积呈幂律关系：例如若要在约38倍更大的空间范围内保持泛化，数据量需要扩展约38^0.35倍；在特定实验设置下，每增加约10倍数据，模型性能可大致按比例提升。[6] 这些研究通常以世界模型或环境生成模型为中枢，借此在仿真中大量采样和学习，再将策略迁移到现实机器人上，从而构成“世界模型辅助控制”的技术路线。

在技术关键词上，世界模型辅助路线通常涉及 world model、sim2real、latent dynamics、model‑based RL 等概念，并与“数据金字塔”“数据幂律 scaling law”紧密相关。[6] 中国信通院发展报告将高质量、超大规模具身数据视为具身基础模型路线的核心支撑资源，并强调数据侧的幂律规律意味着，走世界模型辅助和数据驱动路线的团队需要在数据采集、仿真平台和闭环验证上投入巨大的工程与算力成本。[6][5] 这一路线在当前更多体现在学术系统和实验平台，对产业侧的直接产品形态影响尚在形成之中，但其方法论已深度嵌入具身大模型训练实践。

六、数据驱动/数据金字塔路线

数据驱动/数据金字塔路线与世界模型辅助高度交叉，但更强调从数据规模与结构出发对具身智能系统进行设计。具身智能发展报告在讨论 ManiBox 等实验时指出，空间泛化性能随空间体积和数据量呈幂律增长，要实现更大工作空间内的泛化，需要以幂律方式增加训练数据量，并且每增加一个数量级的数据往往才能获得近似比例的性能提升。[6] 这类结论被视为具身基础模型训练的“数据金字塔”逻辑，即在任务与空间扩展的每一层级，上层性能的提升依赖下层数据规模的成倍扩展。

从路线归类看，数据驱动/数据金字塔并非单独的控制架构，而是一条贯穿其他路线的基础方法论：端到端 VLA、分层大模型、大脑层世界模型以及层级 LLM+RL 均依赖高质量具身数据才能实现泛化。[6][5] 报告因此将“高质量超大规模具身数据”视为一条隐性的技术路线，并指出当前通用具身智能商业化，无论采用端到端还是分层方案，都普遍面临高质量闭环数据严重匮乏的挑战，这对所有路线的落地形成共性约束。[5][6]

七、本体/形态路线与复合多态机器人

除算法与数据侧路线外，产业与学术资料也将本体/形态视为具身智能的一条重要技术维度。中国人工智能学会在《复合多态机器人（2024）》白皮书中提出，以复合多态机器人为代表的可变形、多形态、多模态协同机器人构成具身智能的一条重要技术途径，通过在形态和运动能力上的复合设计提升具身系统的任务适应性和性能，这一路线与以单一人形或单一移动平台为主的具身智能路线形成对照。[8] 白皮书和相关综述认为，复合多态机器人在形态和功能上的重构能力，是技术发展的必然趋势，也符合市场对性能和优势组合的需求。[8]

基于大模型的具身智能系统综述则指出，通用具身智能机器人的本体技术虽然整体成熟，但在引入高自由度灵巧手等部件后，机器人本体自由度显著增加，对高速通信及算力提出更高要求，成本问题尤为突出。[5] 因此，本体/形态路线可以理解为围绕人形、四足、轮式、复合多态等不同平台，在自由度、传感器配置和执行器能力上进行组合和权衡，以适应不同应用场景与成本结构。多份报告也提醒，具身智能的核心驱动力在于深度感知、智能决策和灵巧执行等能力组合，人形外观本身并不是智能化的充分条件，技术评估和路线选择更应围绕感知–规划–控制–执行闭环能力和经济性指标展开。[5]

总体而言，上述路线在技术栈上的位置可粗略归纳为：模块化分层控制和层级 LLM+RL 侧重控制/算法侧，大模型中心和端到端 VLA 侧重“大脑”层，世界模型辅助和数据金字塔侧重数据与训练方法论，本体/形态路线则集中于机电结构与形态设计。[5][6][8] 目前的学术 survey 倾向于按算法和学习范式（如 modular pipeline、LLM for planning、policy learning from demonstration、world‑model‑based control）来命名这些路线，而中国信通院及产业报告更偏向按工程栈和产品形态（如“模块化分层”“分层大模型”“端到端 VLA”“世界模型”“层级 LLM+RL”“复合多态机器人”）进行划分，两种命名在实质路线划分上基本一致，但反映了学术与产业在关注焦点上的差异。[5][6][8]
