## 一、一页纸要点总结

### 1. 具身智能的主要技术路线

从“感知–决策–控制”完整链条出发，目前主流技术路线可概括为：

1. **传统控制 / 经典机器人路线（含少量学习）**  
   - 以动力学/运动学建模 + 轨迹规划 + MPC/采样式控制为核心，感知可用传统视觉或轻量深度学习。  
   - 高度模块化与可解释，已在工业机器人、AGV/AMR、巡检等形成大规模稳定商用。

2. **强化学习 / 模仿学习驱动的策略学习路线**  
   - 通过深度 RL、模仿学习在仿真/现实中直接学习策略，用于高维连续控制、复杂接触任务。  
   - 实践中常与传统控制结合：RL/IL 学“技能”，低层仍由经典控制执行。

3. **端到端大模型（VLA / 行为克隆 / world model）驱动路线**  
   - 典型是 VLA（视觉‑语言‑动作）、世界模型（world model）和大规模行为克隆：从视觉+语言直接输出动作，或通过世界模型在潜空间中“想象”未来，再决定动作。  
   - 代表：Wayve 的 AI Driver + GAIA 世界模型、ELLMER 等。  
   - 目前多处于研究与早期试点阶段。

4. **大模型 + 传统控制/规划的分层混合路线（LLM/VLM 负责高层决策与任务分解）**  
   - 上层 LLM/VLM 负责理解语言指令、任务分解和高层规划，下层用稳定的控制器/MPC/技能网络执行动作，构成“快慢脑”“H‑VLA”架构。  
   - 兼顾大模型智能与工业可控性，是目前 humanoid 和高端工业机器人最主流的工程方案之一。

5. **云端大模型 + 轻终端 / 云–边–端协同路线**  
   - 云/边侧运行大模型与全局规划，端侧只保留实时控制与部分轻量模型，形成“计算域–I/O 中枢–控制域”的三域架构。  
   - 适合算力受限、需要集中调度的多机场景，在中国及云厂商主导的机器人项目中尤为典型。

6. **专用领域机器人具身智能演进路线**  
   - 在工业、仓储、检修、服务等专用场景，把传统机器人逐步“具身智能化”：增加视觉、任务规划、大模型接口，而非一刀切换到通用 humanoid。  
   - 目前是具身智能真正产生可观营收的主力路线。

### 2. 全球发展阶段判断（2018–2025）

- **技术：多路线共存，尚未收敛**  
  - 2018–2020：传统控制 + 深度强化学习为主；  
  - 2021–2023：端到端 VLA、世界模型、SayCan/π0/Helix 等分层混合架构兴起；  
  - 2024–2025：以“world model + 大模型 + 分层控制”为代表的新范式成体系出现。  
  - 当前没有统一“唯一正确”的路线，多条路径在自动驾驶、机器人操作、服务机器人等不同场景并行探索。

- **商业：专用领域先行，通用 humanoid 资本密集但收益未明**  
  - 工业协作机器人、仓储 AGV/AMR、巡检与特种机器人是具身智能的**现金牛**，在传统控制/云端协同框架下已稳定盈利。  
  - humanoid / 通用具身智能在 2024–2025 年资本爆发：  
    - 2025 上半年 humanoid 相关项目融资超过 13 亿美元，近 24 个月累计超过 21 亿美元。  
    - 但大多处于 PoC 或小规模试点阶段，真实营收与可持续商业模式仍在探索。

### 3. 路线 × 区域格局

- **美国**  
  - 在 humanoid / 通用具身智能方面遥遥领先：  
    - 约 28 家 humanoid 创业公司，总融资约 30 亿美元级；Figure、Apptronik、Agility 及 Tesla Optimus、Boston Dynamics、1X 等构筑强势集群。  
  - 技术路线：端到端 VLA/world model 与分层混合路线并行，强调“vision+language+control”的统一。  
  - 商业：主要在仓储、工厂内部试点，Digit 已进入小规模商用；整体仍在早期。

- **中国**  
  - 在专用领域具身智能（工业机器人、仓储机器人、巡检/特种机器人）部署规模大，是当前具身智能收入的重要来源。  
  - humanoid 与机器人基础模型项目数量多、政策推动强，但仍以示范与早期试点为主。  
  - 云–边–端协同、大模型 + 传统控制的工程实践活跃。

- **欧洲、日本及其他亚洲**  
  - 在高端工业机器人、服务机器人和 humanoid 专利储备上具优势（亚洲占 humanoid 专利族约 65%）。  
  - 专用领域机器人商业成熟；通用 humanoid 多处于研发与展示阶段，节奏慢于美国和中国。

## 二、具身智能主要技术路线系统梳理

### 2.1 传统控制 / 经典机器人路线（含少量学习）

**核心思路**

- 以精确或近似精确的动力学/运动学模型为基础，采用：  
  - 轨迹/路径规划（RRT、PRM 等采样式规划）；  
  - 最优控制、MPC、多变量反馈控制；  
  - PID 等经典控制器。  
- 学习主要用于感知和参数标定，而非替代整个控制链。

**关键模型/算法族**

- 规划与控制：MPC、采样式规划、最优控制、轨迹跟踪控制。  
- 感知：传统 CV 与 SLAM，近年加入深度视觉网络（目标检测、位姿估计）。  
- 轻量学习：用于误差补偿、系统辨识的 ML 模型。

**在“感知–决策–控制”中的位置**

- 感知 → 几何/栅格/拓扑表征；  
- 决策 → 基于该表征进行路径和动作规划；  
- 控制 → 高频反馈控制执行规划轨迹。  
- 模块边界清晰，便于验证和安全认证。

**优势/局限**

- 优势：  
  - 高可靠、可解释、工程体系成熟；  
  - 对结构化、重复性任务（焊接、上下料、搬运、巡检）性价比极高。  
- 局限：  
  - 对非结构化环境与多变任务需要大量工程规则；  
  - 对语言、复杂语义的支持弱。

**商业阶段**

- 已在工业机器人、AGV/AMR、巡检与特种机器人中达到**大规模商用成熟期**。  
- 是各类具身智能“加智能”的基座。

---

### 2.2 强化学习 / 模仿学习驱动的策略学习路线

**核心思路**

- 以深度 RL 和模仿学习为核心，在仿真或现实中直接学习策略 π(a|s)：  
  - 模仿学习（BC、IRL、offline RL）从人类示教/遥操作数据学习；  
  - 深度 RL 通过试错优化奖励。  
- 应用于复杂接触、灵巧操作、多步导航等任务。

**关键模型/算法族**

- RL：PPO、SAC、DDPG 等连续控制算法及多智能体变体。  
- IL：行为克隆、逆强化学习、offline RL。  
- LLM 辅助 RL：Code as Policies、LM‑based MPC 等，用 LLM 生成/修改控制代码或代价函数。

**在“感知–决策–控制”中的位置**

- 通常将视觉输入与状态一起进入策略网络，直接输出动作；  
- 工程中常只学“技能层”：策略输出高层动作原语（例如“抓取这里”“向前走一步”），由底层控制执行。

**优势/局限**

- 优势：  
  - 可在难以解析建模的复杂动力学环境中学出有效策略；  
  - 适合利用仿真和遥操作数据进行大规模预训练。  
- 局限：  
  - 样本效率低、训练成本高；  
  - 安全性与稳定性难以保证；  
  - 对开放世界任务泛化仍有限。

**商业阶段**

- 多用于学术研究和大厂内部平台；  
- 在自动驾驶、仓储操作中为策略优化提供辅助；  
- 整体处于**工程试验与局部试点阶段**，多与传统控制或大模型路线结合使用。

---

### 2.3 端到端大模型（VLA / 行为克隆 / world model）驱动路线

**核心思路**

- VLA：从视觉 + 语言输入直接输出动作（位置、关节轨迹、离散指令）。  
- 大规模行为克隆：用大量示教/遥操作轨迹训练 Transformer/序列模型，实现从观测到动作的直接映射。  
- World model：先学世界动力学（例如 GAIA），再基于潜在世界进行规划，最后输出动作。

**关键模型/算法族**

- 多模态 Transformer：Vision encoder + Language encoder + 融合 + Action decoder。  
- 世界模型（video‑world‑model）：从文本生成场景视频、模拟环境动态。  
- 行为克隆模型：大型 seq‑to‑seq 控制模型。

**在“感知–决策–控制”中的位置**

- 将感知与决策高度耦合：同一模型同时理解场景、语言和决定动作。  
- 控制层可以：  
  - 完全由模型输出高频控制；  
  - 或由模型输出低频动作原语，再由传统控制执行。

**典型代表**

- **Wayve（英国，自动驾驶）**  
  - AI Driver：端到端深度学习自动驾驶系统，取代传统 modular 栈。  
  - GAIA：生成式视频世界模型，可从文本生成驾驶视频，用于策略训练与分析。  
  - LINGO：用自然语言训练/解释驾驶模型。  
  - 将自动驾驶视为具身智能的优先落地场景。

- 学术侧：多篇综述系统梳理 RT‑1/RT‑2 等 VLA、world model 在机器人控制中的应用。

**优势/局限**

- 优势：  
  - 统一感知与决策，理论上具有强泛化能力；  
  - 能利用互联网规模多模态数据预训练。  
- 局限：  
  - 可解释性和安全性弱，工业认证难；  
  - 训练与部署成本高；  
  - 多数应用仍需辅助规则与安全冗余。

**商业阶段**

- 自动驾驶：Wayve 等已与车厂合作试点，但仍在“早期商业化探索”；  
- 通用机器人：多集中在实验室演示与少量 PoC；  
- 整体仍为**研究 + 限量试点阶段**。

---

### 2.4 大模型 + 传统控制/规划的分层混合路线

**核心思路**

- 上层（慢脑）：LLM/VLM/VLA 负责：  
  - 语言理解、任务分解、长时序规划；  
  - 选择/编排下层技能。  
- 下层（快脑）：传统控制器、技能网络执行精确动作。  
- 代表架构包括 SayCan、π0、Helix、各种 H‑VLA（分层行动模型）。

**关键模型/算法族**

- 任务规划 LLM：类似 SayCan 的架构，LLM 生成技能序列，结合可行性模型筛选。  
- 分层 VLA：上层 VLA 负责高层动作，底层为专用控制模型。  
- 多技能库 + 调度器：技能以 API 形式暴露，由上层大模型调用。

**在“感知–决策–控制”中的位置**

- 感知：可由 VLM 或传统视觉模块提供。  
- 决策：高层 LLM/VLM 输出“下一步任务/技能”。  
- 控制：底层控制负责安全、实时的闭环动作执行。

**优势/局限**

- 优势：  
  - 兼顾大模型的语义理解与传统控制的稳健；  
  - 工程可演进，可逐步加入新技能；  
  - 更容易适配安全性与合规要求。  
- 局限：  
  - 系统复杂，需要良好接口与调度；  
  - 上层大模型仍可能产生幻觉，需可行性约束。

**商业阶段**

- 多数 humanoid 与“LLM+机器人”项目采取此路线：  
  - 工业/仓储试点中已见到大模型作高层调度、人机交互；  
  - 仍处“试点与小规模商用”阶段，尚未大规模复制。

---

### 2.5 云端大模型 + 轻终端 / 云–边–端协同路线

**核心思路**

- 云/边：训练与运行大模型、世界模型，进行全局策略与规划；  
- 端：部署压缩模型与控制器，负责实时感知、局部规划、执行。  
- 操作系统白皮书提出“计算域–I/O 中枢–控制域”三域架构，有利于实现云–边–端协同。

**关键技术**

- 大模型压缩与蒸馏、量化；  
- 边缘推理加速器；  
- 网络与同步机制（延迟、安全）。

**在“感知–决策–控制”中的位置**

- 感知/决策分布在云与端：  
  - 云：复杂语义理解与多机器人协调；  
  - 端：局部环境理解与实时决策。  
- 控制：端侧控制域负责高频闭环执行。

**优势/局限**

- 优势：  
  - 降低单端设备成本，实现“轻终端”；  
  - 支持多机协同与集中管理。  
- 局限：  
  - 对网络延迟与可靠性敏感；  
  - 安全性与隐私要求高。

**商业阶段**

- 在专用领域已广泛应用：云机器人平台、云调度 AGV/AMR、云语音/对话服务等。  
- 在 humanoid/通用机器人中处于积极探索期。

---

### 2.6 专用领域机器人具身智能演进

**形态**

- 移动类：AGV/AMR、巡检/配送机器人。  
- 操作类：工业机械臂、协作机器人、移动操作平台。

**技术路线组合**

- 传统控制为主、逐步引入：  
  - 深度视觉与感知；  
  - 任务级规划与调度；  
  - 与 LLM/VLM 的接口，用于自然语言配置与人机交互。

**商业成熟度**

- 工业、仓储、检修、服务等多个垂直领域已经形成：  
  - 设备销售 + 项目集成 + 运维服务的稳定商业模式；  
  - 逐步引入 RaaS（Robot‑as‑a‑Service）与平台订阅。  
- 是当前具身智能商业化程度最高的路线。

## 四、“路线 × 商业化阶段”的对比总结

### 4.1 已形成稳定商业模式的路线与代表公司/场景

1. **传统控制 / 经典机器人路线 + 感知增强**  
   - 路线：以 MPC、轨迹规划为核心，配合视觉/传感。  
   - 场景：工业制造、仓储物流、电力/石化巡检、城市服务等。  
   - 代表：  
     - 大量工业机器人厂商与 AGV/AMR 厂商（具体公司超出本次图谱范围）；  
     - Boston Dynamics 的 Spot 与 Stretch 代表“高端传统控制 + 具身智能增强”的成功案例。  
   - 商业模式：设备销售 + 维保 + 项目制集成，部分引入软件订阅。  
   - 区域：  
     - 中国、欧洲、日本部署规模巨大；  
     - 美国也有成熟市场，但近期叙事被 humanoid 稍许稀释。

2. **云端大模型 + 轻终端 / 云–边–端协同**  
   - 路线：云端训练与推理大模型，端侧执行控制。  
   - 场景：云机器人平台、云调度 AGV/AMR、服务机器人、自动驾驶。  
   - 代表：  
     - 各大云厂商牵头的机器人平台项目（具体名称多数未在本图谱显式出现）；  
     - 自动驾驶公司如 Wayve 在云端训练世界模型、端侧部署策略。  
   - 商业模式：平台订阅 + 设备部署 + 运维，逐步向 RaaS 演化。  
   - 区域：  
     - 中国在云–边–端协同方面极为活跃；  
     - 美国/欧洲在自动驾驶与云机器人平台方面走在前面。

3. **专用领域机器人 + 分层混合/轻量大模型增强**  
   - 路线：在工业/服务机器人中引入 LLM/VLM 负责任务配置、人机对话，同时保留底层传统控制。  
   - 场景：可配置的装配/搬运任务、AI 赋能的服务机器人等。  
   - 目前处于**小规模商用**阶段，是大模型下沉到工业场景的现实路径。

### 4.2 主要处于研究或早期试点的路线与代表公司

1. **端到端 VLA / world model 通用机器人**  
   - 路线：VLA/世界模型从视觉+语言直接输出动作或高层控制。  
   - 代表：  
     - 多个学术与大厂实验室项目；  
     - 自动驾驶领域的 Wayve（已进入试点）是较为靠前的实际应用。  
   - 商业阶段：研究与 PoC 阶段，缺乏大规模商用案例。

2. **humanoid / 通用具身智能（大模型驱动 + 分层控制）**  
   - 代表：Figure、Apptronik、Agility Robotics、Tesla Optimus、1X、Robot Era、优必选等。  
   - 路线：  
     - 使用大模型（或规划模型）进行高层决策与人机交互；  
     - 使用传统控制与专用控制网络执行动作；  
     - 部分探索端到端 VLA 或 world model 控制。  
   - 商业阶段：  
     - 资本投入与估值高；  
     - 大多数处 PoC/试点或小规模商用（Digit 较领先）。  
   - 风险：  
     - IP 存量与融资规模不匹配；  
     - 商业模式（RaaS vs 整机销售 + 服务）仍在探索，真实营收有限。

3. **机器人基础模型 / Embodied foundation model**  
   - 代表：Rlwrld 等平台型玩家，以及大厂内部机器人基础模型项目。  
   - 商业阶段：研究与平台阶段，最主要价值在长期生态与跨场景迁移潜力。

### 4.3 区域节奏差异

- **美国**  
  - humanoid / 通用具身智能：  
    - 资金与公司数量领先；  
    - Figure、Apptronik、Agility 等在试点与小规模商用上领先全球。  
  - 专用领域具身智能：  
    - 工业与仓储机器人成熟，但舆论重心更多集中在 humanoid。

- **中国**  
  - 专用领域具身智能：  
    - 工业机器人、仓储 AGV/AMR、巡检/特种机器人是具身智能实际营收主力；  
    - 云–边–端协同与机器人操作系统生态发展速度快。  
  - humanoid / 通用具身智能：  
    - 公司数多、政策导向强；  
    - 目前整体仍在示范与试点阶段，商业成熟度低于专用领域。

- **欧洲、日本及其他亚洲**  
  - 在高端工业与服务机器人上与中国/美国相比不落下风；  
  - humanoid 节奏相对保守，更多关注研发和行业展示。
