## 1. 全球具身智能的主流技术路线

### 1.1 端到端 VLA / 大模型驱动路线
核心思路是把视觉、语言、动作统一到一个模型里，尽量减少传统机器人里“感知-规划-控制”多层拆分，追求通用性和跨任务迁移能力。

- 代表特征：Vision-Language-Action、Diffusion Policy、Transformer policy、world model。
- 优点：泛化潜力高，适合通用 humanoid / mobile manipulation。
- 难点：数据稀缺、长时序任务稳定性、安全与可解释性不足。

代表公司：
- `Tesla`：Optimus
- `Figure AI`
- `1X`
- `Physical Intelligence`

### 1.2 远程操控 + 数据飞轮 + 模仿学习路线
先靠人类遥操作、示教、回放采集高质量数据，再训练策略模型；强调“先做出能用的系统，再用真实数据滚大模型”。

- 代表特征：teleop、demonstration learning、human-in-the-loop。
- 优点：工程落地快，容易形成数据闭环。
- 难点：人力成本高，数据分布受限，规模化依赖硬件与流程设计。

代表公司：
- `Agility Robotics`
- `Apptronik`
- `Sanctuary AI`
- `Figure AI`
- `AgiBot（智元）`

### 1.3 模块化机器人栈 + 传统控制路线
把感知、定位、规划、控制、抓取等模块分开，部分环节引入学习方法，但整体仍以工程系统集成为主。

- 代表特征：传统机器人控制栈、局部引入学习策略。
- 优点：稳定、可调试、适合工业场景。
- 难点：通用性弱，跨场景迁移成本高。

代表公司：
- `Boston Dynamics`
- `UBTECH`
- `Dexterity`
- `Covariant`

### 1.4 仿真 + 强化学习 + 技能库路线
先在仿真中训练 locomotion、抓取、操作技能，再迁移到真机；适合双足、四足、灵巧操作等任务。

- 代表特征：大规模仿真、RL、sim2real、技能库。
- 优点：成本相对低，适合做基础能力。
- 难点：真实世界鲁棒性、奖励设计、长尾场景迁移。

代表公司：
- `Unitree`
- `NVIDIA` 生态中的机器人平台
- `Intrinsic`
- `DeepMind` 相关机器人研究体系

### 1.5 低成本本体 + 规模制造路线
先把本体成本打下来，靠硬件出货、开发者生态和行业试点推动数据与商业化，尤其在中国公司里很典型。

- 代表特征：低成本关节、规模化制造、产品化优先。
- 优点：更容易形成销量、开发者和供应链优势。
- 难点：上层智能能力若跟不上，容易陷入“会动但不好用”。

代表公司：
- `Unitree`
- `UBTECH`
- `AgiBot`
- `Fourier Intelligence`
- `Galbot`

## 2. 代表性公司梳理

## 2.1 `Tesla / Optimus`
- 技术路径：端到端视觉感知 + 大模型/自研算力 + 制造体系协同，强调规模化和软硬件统一。
- 产品进度：Optimus Gen 2 已多次公开展示行走、搬运、分拣、精细动作，仍以工程验证和内部打磨为主。
- 商业化进度：尚未对外规模销售，主要在内部场景验证和演示。
- 融资情况：上市公司，自主现金流与资本市场支持，不依赖外部风险融资。
- 团队情况：马斯克主导，机器人团队与自动驾驶、AI、制造体系深度交叉，优势在工程整合与量产。

## 2.2 `Figure AI`
- 技术路径：VLA / humanoid generalist 路线，强调通用任务执行、端到端学习和快速迭代。
- 产品进度：Figure 01 / Figure 02 已公开展示人机交互、工厂搬运、拣放等能力，并进入工厂试点。
- 商业化进度：处于头部试点阶段，尚未形成大规模收入，但已获得产业伙伴关注。
- 融资情况：2024 年完成标志性大额融资，战略投资人阵容强，包括 Microsoft、OpenAI、NVIDIA、Jeff Bezos 等。
- 团队情况：创始人 Brett Adcock；核心团队来自 Boston Dynamics、Tesla、Google、OpenAI 等，AI 与机器人融合能力强。

## 2.3 `1X`
- 技术路径：偏“安全、可控、可家用”的人形机器人路线，强调人类示教、远程操控和家庭/服务场景。
- 产品进度：EVE / NEO 等产品持续迭代，公开演示较多，强调室内环境适配和安全性。
- 商业化进度：仍以试点和小规模验证为主，尚未进入大规模商业出货。
- 融资情况：累计融资进入较高的风险资本层级，且有顶级 AI 资本背书。
- 团队情况：团队跨挪威与美国，偏工程+AI 混合背景，路线更重视产品可接受性和安全合规。

## 2.4 `Physical Intelligence`
- 技术路径：更偏“机器人基础模型公司”，做通用操作策略与动作模型，而不是先押注单一机器人本体。
- 产品进度：以基础模型、软件栈、策略能力为主，尚无大规模硬件出货。
- 商业化进度：短期更像平台/底层能力供给者，商业化尚在前期。
- 融资情况：成立后即获得顶级 VC 和 AI 圈关注，融资节奏快。
- 团队情况：核心成员多来自顶级 AI 研究与机器人团队，偏算法和基础模型背景。

## 2.5 `Agility Robotics`
- 技术路径：以双足人形机器人 `Digit` 为核心，走“远程操控 + 数据闭环 + 工业物流”的路线。
- 产品进度：Digit 已进入仓储、物流等场景试点，产品成熟度在全球 humanoid 中属于靠前一档。
- 商业化进度：是少数已经接近“可交付部署”的公司之一，仓储物流是其主战场。
- 融资情况：获得 Amazon 等产业资本与多轮 VC 支持，属于“产业+资本”双驱动。
- 团队情况：源自 Oregon State University 的腿足机器人研究传统，强项是动态行走与系统工程。

## 2.6 `Apptronik`
- 技术路径：走工业 humanoid 路线，强调稳定操作、工业任务适配和快速部署。
- 产品进度：`Apollo` 已公开展示并进入多个合作试点，重点是工业与物流场景。
- 商业化进度：处于商业试点扩张期，具备较强的 B 端落地潜力。
- 融资情况：2024 年完成大额融资，资金规模已到数亿美元级别的市场关注度。
- 团队情况：来自 UT Austin / NASA Valkyrie 等机器人传统，机械本体和控制能力强。

## 2.7 `Sanctuary AI`
- 技术路径：强调通用操作能力和类人手部灵巧操作，走“通用人工劳动者”路线。
- 产品进度：`Phoenix` 系列持续迭代，公开展示精细操作、抓取和工具使用。
- 商业化进度：仍以试点和概念验证为主，商业化不如 Agility / UBTECH 明确。
- 融资情况：多轮融资，投资方以北美风险资本和产业支持为主。
- 团队情况：创始人 Geordie Rose 在 AI 界知名度高，团队兼具 AI 研究与硬件工程背景。

## 2.8 `Unitree`
- 技术路径：低成本本体 + 高机动性控制 + 仿真/强化学习，先在四足上跑通，再往 humanoid 扩展。
- 产品进度：四足机器人已经大量出货；人形机器人 `H1 / G1` 也已公开展示并进入开发者与试点市场。
- 商业化进度：是全球少数已经形成真实销量与开发者生态的公司，商业化明显领先大多数纯 demo 公司。
- 融资情况：已进入后期融资阶段，资本市场对其供应链和规模化能力认可度较高。
- 团队情况：创始人王兴兴，典型的工程驱动型团队，强项在本体、关节、控制和成本优化。

## 2.9 `UBTECH`
- 技术路径：服务机器人 + 教育机器人起家，近年全面转向人形机器人与工业场景，走“产品化 + 产业化”路线。
- 产品进度：`Walker S` 等产品已进入工厂、园区等试点。
- 商业化进度：在中国公司里商业化路径最清晰之一，既有存量机器人业务，也有人形新业务。
- 融资情况：已上市公司，具备资本市场融资能力。
- 团队情况：创始人周剑，团队偏制造、产品和渠道，商业落地能力较强。

## 2.10 `AgiBot（智元机器人）`
- 技术路径：强调通用人形机器人 + 真实数据采集 + 产业场景落地，路线介于“模型驱动”和“工程驱动”之间。
- 产品进度：`远征` 系列等产品迭代较快，公开展示频繁，强调工厂、园区和通用服务能力。
- 商业化进度：处于大规模样机验证和行业试点阶段，推进速度较快。
- 融资情况：成立后融资活跃，获得国内头部产业资本和 VC 关注。
- 团队情况：创始团队吸引力强，核心人物彭志辉在国内 AI / 硬件圈知名度高，具备“技术号召力 + 产业资源”双重优势。

## 2.11 `Galbot（银河通用）`
- 技术路径：偏轮式/移动操作与通用操作能力，强调在零售、仓储、服务等场景落地。
- 产品进度：持续发布轮式双臂/移动操作类产品，主打任务执行和通用操作。
- 商业化进度：多为行业试点与场景验证阶段，若能打通零售/物流，商业化空间较大。
- 融资情况：处于活跃融资阶段，投资方以国内一线 VC、产业资本为主。
- 团队情况：北京系创业团队，整体偏算法、感知和移动操作经验。

## 2.12 `Fourier Intelligence`
- 技术路径：从康复机器人、外骨骼和服务机器人延伸到人形机器人，走“医疗/康复 + 通用机器人”融合路线。
- 产品进度：人形与康复相关产品都在持续推进，公开展示较多。
- 商业化进度：康复机器人和医疗相关业务更成熟；人形业务仍处早期探索阶段。
- 融资情况：多轮融资，产业属性较强，且与医疗/康复场景绑定紧密。
- 团队情况：团队偏机电一体化、精密控制和医疗机器人经验，工程属性强。

## 2.13 `Dexterity`
- 技术路径：工业级灵巧操作 + 机器臂/移动平台 + 任务编排，重点解决仓储、分拣、搬运等高频任务。
- 产品进度：已在物流、仓储类场景持续推进，是真正偏“可赚钱”的机器人公司之一。
- 商业化进度：B 端商业化相对成熟，收入模式比纯 humanoid demo 更清晰。
- 融资情况：风险资本支持充足，市场定位明确。
- 团队情况：团队来自机器人、自动化和软件系统背景，强调任务级自动化而非单点炫技。

## 2.14 `Covariant`
- 技术路径：机器人基础模型 + 视觉抓取 + 仓储智能操作，偏“软件定义机器人能力”。
- 产品进度：核心是机器人操作模型和仓储抓取系统，硬件不一定自研，但模型与系统能力突出。
- 商业化进度：在仓储和物流软件化方面有较强落地，属于较成熟的 AI 机器人企业。
- 融资情况：长期受顶级 VC 追捧，后期还与大型科技公司形成深度合作关系。
- 团队情况：强 AI 研究背景，技术偏算法和平台化。

## 3. 这几条路线谁更接近落地

### 3.1 最接近短期商业化
- `Agility Robotics`
- `Dexterity`
- `Covariant`
- `UBTECH`
- `Unitree`

这些公司共同特点是：任务明确、场景封闭、硬件成本可控、客户愿意为节省人工付费。

### 3.2 最接近“通用人形机器人”叙事
- `Tesla`
- `Figure AI`
- `1X`
- `Apptronik`
- `Sanctuary AI`
- `AgiBot`

这些公司更强调“通用劳动者”概念，但距离大规模替代人工仍有明显距离。

### 3.3 最像“下一代机器人基础设施”
- `Physical Intelligence`
- `Covariant`
- `Intrinsic`
- `NVIDIA` 机器人生态

这类公司不一定自己做最显眼的机器人本体，但可能决定未来机器人学习范式和开发方式。

## 4. 结论判断

- 全球具身智能现在不是单一路线竞争，而是“通用大模型路线”与“工程落地路线”同时推进。
- 真正先跑出来的，往往不是最像科幻电影的 humanoid，而是仓储、分拣、搬运、工厂上下料这类高频、可量化 ROI 场景。
- 美国公司更强在基础模型、资本市场和前沿叙事；中国公司更强在硬件成本、供应链、制造效率和出货速度。
- 未来 12–24 个月最值得重点看的，是：
  - 仓储/物流人形机器人是否开始稳定交付
  - 低成本本体是否形成规模销量
  - 机器人基础模型是否真正提升跨任务泛化
  - 家用 humanoid 是否能跨过安全、可靠性和成本三道门槛
