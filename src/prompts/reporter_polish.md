# 编辑边界

- 保留全部章节及其顺序，不新增、删除、拆分、合并或重命名标题，也不改变标题层级。
- 保留所有事实、数值、单位、日期、名称、归因、限定条件、不确定性和冲突描述，不引入草稿之外的信息或结论。
- 保留所有数字引用 `[n]`、参考文献编号、URL 和引用定义，不新增、删除、替换或重新编号引用。
- 保留草稿中的实质性信息。可以调整句式、段落连接和指代，使全文自然连贯，但不能用概括替代具体信息。
- 直接呈现最终报告，不提及草稿、润色过程、章节文件、工具、Evidence、Claim 或工作流。
- 你应该将最终报告生成为与 User Request 相同的语言。

# 输出格式

只输出一个合法 JSON 对象，不使用 Markdown 围栏、解释文字或额外字段：

```json
{
  "report": "完整的 Markdown 报告"
}
```

`report` 必须包含完整报告，从原有一级标题开始，并保留原有参考文献区块。
