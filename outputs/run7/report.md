# 全球具身智能技术路线与代表性公司综述（2022–2025）

## 导言：具身智能产业兴起的背景与研究框架

自2020年前后起，具身智能被多份产业报告视为继互联网和移动互联网之后的新一轮技术拐点，其发展历程被划分为哲学与概念提出期（约1950–2000年）、关键技术积累期（2000–2020年）以及大模型驱动的应用拓展期（2020年以来），当前阶段的典型特征是“通用大模型＋机器人”的技术范式集中涌现。 [1][2][3][4][5][6][7]

中国信息通信研究院和多家券商机构的报告指出，2025年初“具身智能”首次被写入政府工作报告，和“智能机器人”共同被列为未来产业重点发展方向，标志着具身智能从学术前沿走向国家层面的产业布局。 行业报告进一步预期，全球具身智能市场规模在2025年有望达到约192亿元人民币，未来五年复合增长率接近73%，在十年左右时间有望逼近年万亿级市场需求。 另一方面，Grand View Research 等机构的预测也显示，到2030年人形机器人、L1–L3 自动驾驶汽车和无人机等相关市场合计规模可达约3398.4亿美元，这从需求侧印证了具身智能所依托的机器人与自动化市场空间。 [1][2][3][4][5][6][7]

在中国，本轮具身智能产业的快速起势与政策和资本双重驱动密切相关。产业研究报告的统计显示，截至2025年12月，中国具身智能及机器人领域已披露的投资事件约为744起，融资总额约735.43亿元人民币，资本涌入力度显著。 多份报告同时指出，自2023年中以来，国内已建设约两个国家级和五个省级人形机器人或具身智能创新中心，对应《“机器人+”应用行动实施方案》、人形机器人创新发展指导意见等国家政策，以及北京、上海、杭州等地在2024–2025年密集出台的具身智能和人形机器人产业规划与实施方案。 这些创新平台与地方行动计划在资金、试点场景、标准制定等方面为具身智能技术路线提供了试验田和护城河。 [1][2][3][4][5][6][7]

从技术演进视角看，行业和学术综述普遍将当前通用具身智能系统抽象为“大脑–小脑–本体”三层技术栈：其中“大脑”对应具身基础大模型和任务理解模块，“小脑”对应运动控制与执行层，“本体”对应机器人机电结构与执行器。 报告指出，本体和传统运动控制技术相对成熟，但在集成灵巧手等高自由度部件后，自由度和通信、算力需求显著增加，成本成为突出瓶颈。 相比之下，“大脑”层的具身基础大模型截至2025年仍主要停留在实验室研发阶段，在训练数据规模与质量、具身场景专用训练方法、语言模型物理推理和工具使用能力、推理效率优化等方面存在尚待解决的问题。 技术路线层面，产业与学术资料将当前阶段概括为从“基于模型/基于学习的传统运动控制”向“通用大模型＋机器人”范式演进，其中大语言模型负责任务理解与代码生成，视觉语言模型负责环境语义理解，视觉语言动作（VLA）模型承担端到端动作策略生成，这一范式构成了具身智能的一条核心技术路线。 [1][2][3][4][5][6][7]

在市场和团队维度，基于大模型的具身智能系统综述与产业报告将当前创业与研发力量的技术基因大致划分为三类：一是以传统硬件与运动控制为核心能力的团队，二是以计算机视觉与自动驾驶技术为基础的团队，三是以大模型与强化学习为主的团队。 报告认为三类团队在软件算法深度、机电系统工程化能力和商业化落地经验等维度各有长短，构成了当下多样化的技术路线组合。 同时，产业分析也提醒，与终极外观形态（例如人形）相比，具身智能的核心驱动力在于深度感知、智能决策、泛化交互和灵巧执行等智能能力组合，人形外观本身并不是智能化或商业成功的充分条件，评估应更加关注感知–规划–控制–执行闭环能力以及回本周期等可量化指标。 [1][2][3][4][5][6][7]

基于上述背景，本报告在技术层面将重点围绕几类被反复提及的主要路线：模块化分层控制路线、以 LLM/VLM 为核心的分层大模型＋skill API 路线、端到端 VLA 路线、层级 LLM+RL 路线、世界模型辅助路线以及数据驱动/数据金字塔路线，同时将本体/形态（如人形、四足、复合多态机器人）视为横向维度进行比较。 在公司层面，报告主要依托中国信通院、行业研究机构及商用具身智能白皮书中披露的代表性企业及其融资与产品信息，这些资料集中列出了 Figure AI、1X Technologies、Agility Robotics、Apptronik、Field AI 等海外公司，以及银河通用、宇树科技等国内公司在不同时间的融资轮次、金额与估值数据。 然而，需强调的是：一方面，公开报告中关于技术架构、数据路线、应用场景的细节描述往往以典型案例和定性概括为主，难以构成全量公司级矩阵；另一方面，融资金额、估值和团队背景等信息存在时间滞后和选择性披露，本报告仅能在有限范围内引用可追溯的公开数据。 因此，后续各章节关于技术路线覆盖度、公司样本代表性以及融资/团队信息完备性均存在一定局限，相关结论应被理解为基于当前公开资料的阶段性整理，而非对全球具身智能产业全景的穷尽性刻画。 [1][2][3][4][5][6][7]

## 全球具身智能主要技术路线分类与技术特征

在2022–2025年的学术综述和产业报告中，具身智能技术路线已形成相对清晰的多路并行格局。中国信通院具身智能发展报告以及《基于大模型的具身智能系统综述》等文献，将当前通用具身智能系统抽象为“大脑–小脑–本体”技术栈，并据此区分控制/算法侧、大模型“脑”侧、数据侧与本体/形态侧的不同技术路径。下文将依据这些资料，对主要路线进行分类与简要特征说明。 [3][2][1][7]

一、模块化分层控制路线 [3][2][1][7]

传统机器人领域长期以“感知–规划–控制–执行”的模块化分层架构为主流，具身智能阶段的许多系统仍在这一框架上演化。行业报告指出，多时间尺度分层控制是具身智能系统的技术刚需：高层任务规划和决策通常在约1–10 Hz 频率运行，而低层本体控制环路需要至少100 Hz 甚至更高的频率，以保证稳定和安全。 在这一路线中，感知模块（可包含 SLAM、视觉识别等）与规划模块（路径规划、任务分解）保持相对独立，由运动控制器（如 MPC、WBC 等）在高频环路输出具体扭矩或速度指令。 [3][2][1][7]

中国信通院报告明确提到，以大模型驱动的具身智能并未完全替代传统控制，而是在“通用大模型＋控制器”的组合中保留了模块化分层：大语言模型或规划模块负责高层策略，传统控制器或强化学习策略负责低层动作，这种“LLM 设高层策略＋控制器/ RL 生成底层动作”的分工，实质上属于模块化分层控制的扩展版本。 因此，模块化分层路线可以理解为以经典控制和分层架构为骨干，逐步吸纳大模型和学习算法，但在工程实现上仍强调清晰的接口与安全冗余，适合对实时性和可靠性要求极高的工业和移动机器人场景。 [3][2][1][7]

二、分层大模型（LLM/VLM+skill APIs）路线 [3][2][1][7]

基于大模型的具身智能系统综述将“大模型中心”视为一条独立技术路线，其典型形态是以大语言模型、大型视觉模型或多模态基础模型作为“大脑”，通过代码生成、技能调度和 API 调用实现高层任务规划与技能编排。 报告描述的技术演进路径是：从传统基于模型和基于学习的运动控制阶段，发展到“通用大模型＋机器人”阶段，其中大语言模型用于任务理解与代码生成，视觉语言模型用于环境语义理解，视觉语言动作（VLA）模型用于端到端动作策略生成。 [3][2][1][7]

在分层大模型路线中，LLM/VLM 通常不直接输出关节级指令，而是通过 skill APIs 或中间 DSL 调用一组预定义或学习得到的技能库。学术综述中将“LLM for planning”“policy learning from demonstration”“world‑model‑based control”等关键词归入这一类路线，强调其特点是利用基础模型承担通用认知与符号规划，再由下游策略或控制模块执行具体动作。 中国信通院报告也指出，许多具身智能系统采用“高层通用大模型＋低层传统控制或 RL”的结构，在技术栈上表现为“大脑”侧的大模型与“小脑”侧的控制模块解耦。 这一路线的优势在于任务理解和跨任务迁移能力较强，工程上可以通过 API 封装将技能库不断扩展，但其瓶颈在于：具身基础模型仍主要停留在实验室研发阶段，在数据规模与质量、训练方法以及物理推理和工具使用能力方面存在明显不足，影响了整体闭环性能。 [3][2][1][7]

三、端到端 VLA 路线 [3][2][1][7]

端到端视觉–语言–动作（Vision‑Language‑Action, VLA）模型是近年具身智能最受关注的路线之一。行业报告将 Google Robotics 的 RT‑1 视为端到端 Transformer 控制路线的代表：RT‑1 能在家庭厨房场景执行700余种具体任务，在约3000次真实测试中平均成功率约97%，显示出较强语义泛化和任务扩展能力。 这一类系统通常以多模态传感输入（图像、文本指令等）直接映射到动作序列，弱化显式规划模块，从而在特定平台与场景内实现“指令到动作”的一体化控制。 [3][2][1][7]

然而，中国信通院发展报告与综述普遍强调，端到端 VLA 路线当前存在若干结构性局限：一是泛化性有限，模型性能与具体机器人本体强相关，跨本体迁移时难以复现原有性能；二是长程任务执行能力不足，在“整理垃圾”“物品交换”等家庭长程任务上，结合分层 Gemini Robotics‑ER 1.5 与 Gemini Robotics 的 VLA 模型的系统成功率多在约20%–40%；三是软硬协同难，高层规划和决策处理频率约在1–10 Hz，而低层本体控制频率需至少100 Hz，这种时间尺度差异显著增加了端到端方案在真实系统中的工程复杂度。 因此，端到端 VLA 路线在受控环境和特定平台下已展示出高性能样板，但在通用真实环境、大规模多本体部署和安全可控要求下仍处于探索阶段。 [3][2][1][7]

四、层级 LLM+RL 路线 [3][2][1][7]

另一条被频繁提及的路线是层级 LLM+RL 控制。产业综述以 Hi‑Core 结构为代表，指出其强化学习部分分两层：上层由大语言模型设高层策略，下层由强化学习生成低层动作。 行业报告进一步将这一架构概括为“LLM 指挥高层任务规划＋RL 在高频环路生成具体控制”，并强调在具身智能控制路线中，多时间尺度分层控制是一条重要技术路径：高层策略模块工作在1–10 Hz 的低频，高频控制环路则由 RL 或经典控制器在≥100 Hz 的频率下执行动作。 [3][2][1][7]

从“大脑–小脑–本体”视角看，层级 LLM+RL 路线的“大脑”侧由通用大模型承担任务理解和分解，“小脑”侧则由 RL 或混合控制器承担具体动作生成，本体侧仍依赖成熟的机电结构。 与端到端 VLA 相比，这一路线更强调显式规划与多层次控制，在长程、多步骤任务上具备潜在优势；但其工程复杂度较高，需要同时解决 LLM 提示工程、RL 策略稳定性以及软硬协同的接口设计问题。现阶段公开资料更多是原型系统和实验性架构，尚未形成统一的工业标准，但在学术与产业调查中已被明确标注为具身智能的一条重要技术路径。 [3][2][1][7]

五、世界模型辅助路线 [3][2][1][7]

世界模型辅助路线以显式构建环境动态或任务世界模型为特征，在具身智能基础模型研究中被视为重要方法论。中国信通院报告引用 ManiBox 和 GEN‑0 等工作指出，空间泛化所需数据量与空间体积呈幂律关系：例如若要在约38倍更大的空间范围内保持泛化，数据量需要扩展约38^0.35倍；在特定实验设置下，每增加约10倍数据，模型性能可大致按比例提升。 这些研究通常以世界模型或环境生成模型为中枢，借此在仿真中大量采样和学习，再将策略迁移到现实机器人上，从而构成“世界模型辅助控制”的技术路线。 [3][2][1][7]

在技术关键词上，世界模型辅助路线通常涉及 world model、sim2real、latent dynamics、model‑based RL 等概念，并与“数据金字塔”“数据幂律 scaling law”紧密相关。 中国信通院发展报告将高质量、超大规模具身数据视为具身基础模型路线的核心支撑资源，并强调数据侧的幂律规律意味着，走世界模型辅助和数据驱动路线的团队需要在数据采集、仿真平台和闭环验证上投入巨大的工程与算力成本。 这一路线在当前更多体现在学术系统和实验平台，对产业侧的直接产品形态影响尚在形成之中，但其方法论已深度嵌入具身大模型训练实践。 [3][2][1][7]

六、数据驱动/数据金字塔路线 [3][2][1][7]

数据驱动/数据金字塔路线与世界模型辅助高度交叉，但更强调从数据规模与结构出发对具身智能系统进行设计。具身智能发展报告在讨论 ManiBox 等实验时指出，空间泛化性能随空间体积和数据量呈幂律增长，要实现更大工作空间内的泛化，需要以幂律方式增加训练数据量，并且每增加一个数量级的数据往往才能获得近似比例的性能提升。 这类结论被视为具身基础模型训练的“数据金字塔”逻辑，即在任务与空间扩展的每一层级，上层性能的提升依赖下层数据规模的成倍扩展。 [3][2][1][7]

从路线归类看，数据驱动/数据金字塔并非单独的控制架构，而是一条贯穿其他路线的基础方法论：端到端 VLA、分层大模型、大脑层世界模型以及层级 LLM+RL 均依赖高质量具身数据才能实现泛化。 报告因此将“高质量超大规模具身数据”视为一条隐性的技术路线，并指出当前通用具身智能商业化，无论采用端到端还是分层方案，都普遍面临高质量闭环数据严重匮乏的挑战，这对所有路线的落地形成共性约束。 [3][2][1][7]

七、本体/形态路线与复合多态机器人 [3][2][1][7]

除算法与数据侧路线外，产业与学术资料也将本体/形态视为具身智能的一条重要技术维度。中国人工智能学会在《复合多态机器人（2024）》白皮书中提出，以复合多态机器人为代表的可变形、多形态、多模态协同机器人构成具身智能的一条重要技术途径，通过在形态和运动能力上的复合设计提升具身系统的任务适应性和性能，这一路线与以单一人形或单一移动平台为主的具身智能路线形成对照。白皮书和相关综述认为，复合多态机器人在形态和功能上的重构能力，是技术发展的必然趋势，也符合市场对性能和优势组合的需求。 [3][2][1][7]

基于大模型的具身智能系统综述则指出，通用具身智能机器人的本体技术虽然整体成熟，但在引入高自由度灵巧手等部件后，机器人本体自由度显著增加，对高速通信及算力提出更高要求，成本问题尤为突出。 因此，本体/形态路线可以理解为围绕人形、四足、轮式、复合多态等不同平台，在自由度、传感器配置和执行器能力上进行组合和权衡，以适应不同应用场景与成本结构。多份报告也提醒，具身智能的核心驱动力在于深度感知、智能决策和灵巧执行等能力组合，人形外观本身并不是智能化的充分条件，技术评估和路线选择更应围绕感知–规划–控制–执行闭环能力和经济性指标展开。 [3][2][1][7]

总体而言，上述路线在技术栈上的位置可粗略归纳为：模块化分层控制和层级 LLM+RL 侧重控制/算法侧，大模型中心和端到端 VLA 侧重“大脑”层，世界模型辅助和数据金字塔侧重数据与训练方法论，本体/形态路线则集中于机电结构与形态设计。 目前的学术 survey 倾向于按算法和学习范式（如 modular pipeline、LLM for planning、policy learning from demonstration、world‑model‑based control）来命名这些路线，而中国信通院及产业报告更偏向按工程栈和产品形态（如“模块化分层”“分层大模型”“端到端 VLA”“世界模型”“层级 LLM+RL”“复合多态机器人”）进行划分，两种命名在实质路线划分上基本一致，但反映了学术与产业在关注焦点上的差异。 [3][2][1][7]

## 技术路线间的系统对比：数据需求、泛化能力与工程复杂度

在上一章的分类基础上，端到端 VLA、分层大模型（LLM/VLM+skill APIs）、层级 LLM+RL 和世界模型辅助路线共同构成当前具身智能的几条主干技术路径。尽管具体模型和系统名称在不同文献中不尽相同，但中国信通院具身智能发展报告及《基于大模型的具身智能系统综述》等材料在多处指出，这几条路线在数据需求、任务表现、泛化与工程复杂度上的差异已经较为清晰。 [3][2][1][7]

（一）数据规模与质量需求的差异 [3][2][1][7]

从数据驱动视角看，几条路线对数据的依赖呈现不同特征。具身智能发展报告将端到端 VLA 路线视为高度依赖闭环具身数据的方案：例如 Google Robotics 的 RT‑1 通过在家庭厨房场景采集大量真实操作数据，训练出能够执行700余种任务的模型，并在约3000次测试中取得平均约97%的成功率。 这展示了在单一平台和限定场景下，端到端路线可以通过聚焦数据采集实现高性能，但也意味着其泛化能力高度受限于数据覆盖的任务和环境分布。 [3][2][1][7]

世界模型辅助和数据金字塔路线则从理论和实证层面揭示了数据需求的幂律特征。中国信通院报告引用 ManiBox 等工作指出，空间泛化所需数据量与空间体积呈幂律关系：例如要在约38倍更大的空间范围内实现泛化，数据量需要扩展大约38^0.35倍；在特定设置下，每增加约10倍训练数据，模型性能可大致按比例提升。 报告由此将高质量、超大规模具身数据视为具身基础模型的核心支撑资源，并强调无论是端到端 VLA、分层大模型还是层级 LLM+RL 路线，如果想在更大任务空间和更多本体上实现泛化，都必须遵守这一“数据金字塔”逻辑。 [3][2][1][7]

相比之下，分层大模型和层级 LLM+RL 路线在一定程度上可以通过“以语言知识和通用视觉模型补数据”的方式缓解纯具身数据需求，但综述指出，大脑层通用具身基础模型截至2025年仍主要停留在实验室研发阶段，在具身场景专用数据规模和质量、训练方法以及语言模型在物理推理和工具使用方面的固有缺陷上存在关键短板。 因此，从数据侧看，端到端 VLA 的优势在于一旦获得足量高质量闭环数据，即可在特定平台显著提升表现；分层大模型和层级 LLM+RL 的优势在于可以复用通用语义和视觉预训练知识以减少专用数据压力；世界模型辅助路线则通过仿真和生成建模在理论上放大数据采样能力，但受限于 sim2real 以及仿真逼真度问题。 [3][2][1][7]

（二）短程/长程任务表现对比 [3][2][1][7]

在任务时长与复杂度维度，端到端 VLA 与分层路线的差异更加明显。具身智能发展报告在评估端到端 VLA 时指出，目前代表性系统尚未形成稳定的“感知–决策–执行”闭环，在跨环境和跨本体的长程任务上，系统成功率多在20%–40%区间。 报告以整理垃圾、物品交换等家庭长程任务为例，指出即便结合分层 Gemini Robotics‑ER 1.5 与 Gemini Robotics 的 VLA 模型，整体系统在多步骤任务上的成功率仍然受限。 相比之下，在短程、结构化的厨房操作任务上，RT‑1 这类端到端模型可以在约700个任务上达到接近97%的成功率，说明端到端路线在短程、场景受控的任务上具有较强优势。 [3][2][1][7]

分层大模型（LLM/VLM+skill APIs）以及层级 LLM+RL 路线则通过显式任务分解和多时间尺度控制来提升长程任务能力。产业综述以 Hi‑Core 等架构为例，描述其通过上层大语言模型设高层策略、下层强化学习生成低层动作，实现两层控制。 报告同时强调，多时间尺度分层控制在具身智能系统中是一条重要技术路径：高层任务规划和决策通常在1–10 Hz 的低频率运行，而低层本体控制需要≥100 Hz 的高频环路。 这种结构使得系统在处理长程、多步骤任务时可以保持策略一致性和局部纠错能力，但也带来工程复杂度的提升。 [3][2][1][7]

世界模型辅助路线在长程任务表现上更多依赖“在世界模型中规划，再在真实环境执行”的思路。具身智能发展报告指出，通过在仿真环境中训练政策并利用世界模型进行长程规划，可以在一定程度上提升复杂任务中的策略稳定性和探索效率，但当前 sim2real gap 和世界模型逼真度仍限制了这一路线在真实复杂环境中的表现。 综合来看，端到端 VLA 路线在短程、局部任务表现突出，分层大模型和层级 LLM+RL 在长程任务和多步骤策略上更具结构优势，世界模型辅助路线则从规划和仿真侧提供潜在增益，但尚处于探索阶段。 [3][2][1][7]

（三）跨场景与跨本体泛化能力 [3][2][1][7]

在泛化维度，中国信通院报告对端到端 VLA 路线给出了较为审慎的评价：现有 VLA 模型性能表现与本体强相关，在跨本体迁移时很难复现模型性能；在跨场景泛化方面也存在明显局限。 即便是 RT‑1 这类在目标平台和场景内表现优异的系统，在迁移到不同形态或显著不同任务空间时仍面临数据分布和平台差异的挑战。 [3][2][1][7]

相比之下，分层大模型路线通过将任务理解和技能编排抽象为语言与 API 层，在理论上更有利于跨场景迁移：高层任务描述可以保持相对稳定，底层技能库和本体适配可以按场景进行扩展或替换。 层级 LLM+RL 路线则在高层策略与低层动作之间引入明晰的接口，使得在迁移到新场景或本体时，可以局部替换 RL 策略或控制器，而保留高层任务理解能力。 不过综述指出，大脑层具身基础模型在跨场景和跨本体物理推理能力上仍然不足，这是所有以大模型为“脑”的路线共同面临的问题。 [3][2][1][7]

世界模型辅助及数据金字塔路线在泛化能力上从数据和模型结构两侧提供支持：幂律数据分析表明，随着空间体积放大，若保持泛化水平不变，数据规模需按幂律扩展，这为跨场景泛化提供了量化约束。 同时，世界模型的显式结构可以帮助策略在虚拟环境中体验更多场景变化，从而提升泛化潜力。但报告也提醒，世界模型的偏差和训练数据的覆盖度直接影响泛化效果，sim2real gap 仍是关键瓶颈。 [3][2][1][7]

（四）控制频率、实时性与软硬协同复杂度 [3][2][1][7]

多份报告在讨论具身智能控制路线时，都强调了“多时间尺度控制”与软硬协同的难度。具身智能发展报告给出定量示例：针对高层次任务规划和决策，处理频率大概在1–10 Hz，而针对低层次本体控制频率需至少在100 Hz以上。 在端到端 VLA 路线中，一般由单一大模型或数个联结的模型覆盖从感知到动作的全过程，在软硬协同上需要同时满足慢速高层策略与高速低层控制的需求，这显著增加了工程复杂度，尤其是在安全和稳定性要求高的场景。 [3][2][1][7]

分层大模型与层级 LLM+RL 路线通过明确分拆高低层模块来缓解这一问题：高层通用大模型主要在较低频率上运行，负责指令、规划和策略选择，低层控制器或 RL 模块则在高频环路中执行动作，从而使得软硬接口更加清晰。 不过，这也要求系统在模块间设计可靠的接口协议和故障隔离机制，防止高层模型的误判通过低层环路放大为危险动作。世界模型辅助路线在控制频率上可以通过在仿真环境中进行大规模离线训练，然后在真实系统中只部署经过验证的策略，从而部分降低在线实时推理压力，但最终系统仍需满足上述多时间尺度控制要求。 [3][2][1][7]

综合而言，端到端 VLA 路线在工程上追求极简的模块数量，但在软硬协同和实时控制方面承受较大压力；分层大模型和层级 LLM+RL 路线在控制频率和接口设计上更符合传统工程实践，但需要解决跨模块协调与全局稳定性问题；世界模型辅助路线则以仿真和离线规划为重点，在实时控制环节中依赖既有控制架构。 [3][2][1][7]

（五）综合评价与适用场景 [3][2][1][7]

基于上述比较，中国信通院及相关综述给出的阶段性判断是：截至2025年初，通用具身智能商业化，无论采用端到端 VLA 还是分层“大模型＋控制器”方案，均普遍面临“感知–规划–控制–执行”闭环算法尚不成熟以及高质量具身数据严重匮乏的挑战，这对各条路线的工程化落地形成共性约束。 在此基础上，可以做出相对谨慎的路线适用性分析：在数据相对可控、任务边界清晰且安全风险较低的场景（如受限家务、简单搬运和结构化操作），端到端 VLA 路线凭借其一体化控制和较高短程任务成功率，具有一定试点优势，但跨场景和跨本体扩展仍需显著的再训练和数据采集。 [3][2][1][7]

在需要长程、多步骤任务规划且安全要求高的工业或服务机器人场景，分层大模型和层级 LLM+RL 路线更符合当前工程实践，通过显式规划和多时间尺度控制提升系统可解释性和稳定性，但也需要更复杂的系统集成和测试流程。 对于希望在大规模、多场景环境中部署具身基础模型的团队，世界模型辅助和数据金字塔路线提供了方法论支撑，强调通过世界模型和仿真平台进行数据放大和策略预训练，但受限于 sim2real gap 和世界模型精度，这一路线短期内更适合作为其他路线的训练基础设施，而非直接的部署架构。 [3][2][1][7]

总体来看，当前具身智能尚处于大模型驱动的新拐点期，端到端、大模型中心、分层控制和世界模型辅助路线仍在并行探索阶段。学术综述倾向按算法与学习范式区分 modular pipeline、LLM for planning、policy learning from demonstration、world‑model‑based control 等标签，而产业与政策报告则侧重“大模型＋机器人”“端到端 VLA”“层级 LLM+RL”“世界模型”“复合多态机器人”等术语，两种视角在路线划分上的重合部分，构成了未来数年具身智能技术演进的主要轨道。 [3][2][1][7]

## 具身智能代表公司矩阵：技术路径、产品与商业化进度

结合商用具身智能白皮书、具身智能发展报告以及赛道投资策略报告等资料，可以在技术路线和本体形态两个维度上梳理当前具身智能代表公司矩阵。需说明的是，这些资料以公开披露的典型企业为主，对全球范围内所有公司并不穷尽，许多企业的详细技术架构、数据路线和团队信息未公开，以下分析仅反映公开报告中的代表性样本。 [1][2][3][4][6][5][7]

（一）按技术路线与本体形态划分的公司谱系 [1][2][3][4][6][5][7]

从技术路线看，行业报告将当前具身智能和人形机器人创业团队的技术基因划分为三类：传统硬件与运动控制背景、计算机视觉与自动驾驶背景以及大模型与强化学习背景。三类团队在软件算法、机电系统工程化和商业化推进能力上各有优势与短板，对应不同的技术路线组合。 [1][2][3][4][6][5][7]

从本体形态看，报告指出单一形态机器人的全球市场规模约为600亿元人民币，其中物流机器人这一单场景形态全球市场约360亿元人民币，显示传统单一形态机器人市场已具规模，但仍相对独立。 与之对照，中国人工智能学会白皮书和相关报道将复合多态机器人视为具身智能的一条重要技术路径，认为复合多态机器人是技术发展的必然趋势，是市场对性能和优势的一种选择，其设计理念和技术实现正在推动具身智能的发展。云迹科技的复合多态机器人 UP 即是这一路线的代表：报道描述其可以在不同时间段切换“送餐员”“清洁工”“巡逻员”等角色，在酒店、医疗、工厂和楼宇等场景实现规模化落地，通过多角色切换提升设备利用率并降低多设备采购成本。 [1][2][3][4][6][5][7]

在人形机器人维度，商用具身智能白皮书和机器人大模型报告将特斯拉 Optimus、Figure AI、Agility Robotics、Apptronik、Field AI 等视为国际具身智能与人形机器人代表公司。特斯拉的 Optimus 项目以“自动驾驶技术＋完全自研本体”为主线，Figure AI、Agility Robotics 等则更多从机器人本体和场景应用角度切入，并逐步引入大模型和端到端控制架构。 [1][2][3][4][6][5][7]

（二）海外代表公司：人形与通用具身智能 [1][2][3][4][6][5][7]

1. Figure AI 与 1X Technologies [1][2][3][4][6][5][7]

商用具身智能白皮书披露，Figure AI 在2025年9月完成超过10亿美元的 C 轮融资，最新估值约390亿美元；1X Technologies 同期处于约10亿美元融资中的状态，估值约100亿美元。 报告将二者归入人形机器人和通用具身智能赛道的头部公司，并强调这类公司多采用“人形＋具身大模型”的技术路线，通过大模型承担高层认知与规划，本体承担执行与交互。 [1][2][3][4][6][5][7]

在技术路径上，行业综述指出大模型（LLM、LVLM、VLA 等）正在成为具身系统的核心载体，广泛用于任务理解、代码生成、世界模型构建和端到端动作策略学习。 Figure AI 和 1X 虽未在这些报告中给出详细架构，但被归为以大模型为“脑”、以人形或多形态本体为“体”的代表性公司，其路线与端到端 VLA、分层大模型和层级 LLM+RL 的组合高度相关。 [1][2][3][4][6][5][7]

2. Agility Robotics 与 Apptronik、Field AI 等 [1][2][3][4][6][5][7]

白皮书列出多家海外具身智能公司融资数据：Agility Robotics 在2022年4月完成约1.5亿美元 B 轮融资，估值约12.6亿美元；Apptronik 在2025年2月完成约3.5亿美元 A 轮融资，估值约14.4亿美元；Field AI 在2025年8月完成约3.14亿美元 A 轮融资，估值约2亿美元；Physical Intelligence 与 Skild AI 在2024年完成约3–4亿美元级 A 轮融资。 报告将这些公司统一归入人形或通用具身机器人赛道，强调它们在本体与场景方面各有侧重：Agility 更侧重物流和仓储场景，人形本体用于搬运与协作；Apptronik 和 Field AI 则探索更多工业与服务场景。 [1][2][3][4][6][5][7]

从技术路线角度，机器人大模型报告指出，端到端 Transformer 控制模型 RT‑1、RT‑2、SayCan、π0 等构成了具身智能的大模型样板，人形和通用具身机器人公司多在此基础上结合自家本体与场景进行工程化改造。 虽然报告未对每家公司给出具体架构，但在产业分析中，Agility 等公司一般被认为采取“感知–规划–控制”的分层路线，并逐步引入大模型和 VLA 控制以提升泛化能力。 [1][2][3][4][6][5][7]

（三）国内代表公司：通用具身终端与复合多态平台 [1][2][3][4][6][5][7]

1. 智平方（Qisquare）：通用具身终端＋端到端具身大模型 [1][2][3][4][6][5][7]

具身智能发展报告将智平方列为典型通用具身智能创业公司之一，并提供相对丰富的公司级信息。报告描述，智平方（深圳）科技有限公司成立于2023年4月，定位为 RoboService 公司，致力于研发生产通用智能具身终端，为工业与家庭等多场景提供全场景、高可靠服务；其创始人郭彦东为美国普渡大学博士，师从美国工程院院士 Jan P. Allebach 和 Charles A. Bouman，拥有超过15年 AI 学术研究和产业实践经验，被公司描述为“国家级创新领军人才”。 [1][2][3][4][6][5][7]

在融资方面，智平方于2025年1月宣布完成数亿元人民币的 Pre‑A 轮战略融资，由达晨财智和敦鸿资产联合领投，基石资本跟投，历史投资人还包括 SEE Fund、清智资本和国投创盈等机构。报告称这是2025年具身智能领域首笔重大融资事件之一。 [1][2][3][4][6][5][7]

在技术路径上，智平方与北京大学在2024年6月联合推出面向操作机器人的 RoboMamba 端到端具身大模型，报告援引公司口径指出该模型早于 PI 的 OpenVLA 公开应用，并在未见任务的泛化能力上显著优于 Google 的 RT 系列模型，相关成果入选 NeurIPS 2024，被视为中国具身创业公司在 VLA 端到端方向的重要国际发声案例。 这表明智平方在端到端 VLA 路线上处于国内较为领先的位置，并明确采用“大模型＋具身终端”的技术范式。 [1][2][3][4][6][5][7]

在商业化维度，报告披露智平方已与多家国内外一线车企、高端制造企业及互联网公司签约，获得大量商业订单，并在2024年实现数千万元人民币确认收入，自我定位为国内最早进行通用智能机器人商业推广的公司之一。 不过，除这些公开数据外，具体客户名单、应用场景细节和回本周期测算并未详细披露，相关商业化评估仍有信息空白。 [1][2][3][4][6][5][7]

2. 银河通用、宇树科技、自变量、星海图、星动纪元、云深处等 [1][2][3][4][6][5][7]

机器人大模型报告给出多家国内具身智能及机器人企业的融资情况：银河通用在2025年6月完成约11亿元人民币 Pre‑A 轮融资，最新估值约4.25亿美元；自变量在2025年9月完成约10亿元人民币 A+ 轮融资；星海图在2025年7月获得约1.22亿美元等值的天使+轮融资；宇树科技在2025年6月完成约7亿元人民币 C 轮融资；星动纪元在2025年7月完成约5亿元人民币 A 轮融资；云深处在2025年7月完成约5亿元人民币 C 轮融资。 报告将这些公司统称为人形或具身机器人赛道的重要参与者，但对各自技术架构和团队背景未展开详细介绍，仅在宏观层面指出当前市场以传统硬件与运动控制、CV/自动驾驶以及大模型/强化学习三类背景团队为主。 [1][2][3][4][6][5][7]

在技术路线与本体形态维度，这些公司大多布局人形或复合多态机器人：例如部分企业推出轮式＋机械臂的复合形态平台，或面向工厂、仓储和楼宇场景提供具身机器人解决方案；但公开报告中关于其是否采用端到端 VLA、大模型中心、分层 LLM+RL 或世界模型辅助等具体架构的信息有限，难以形成统一的技术矩阵，只能在宏观层面将其归为“具身智能＋机器人本体”路线的代表公司。 [1][2][3][4][6][5][7]

3. 云迹科技与复合多态机器人 UP [1][2][3][4][6][5][7]

在复合多态机器人维度，世界互联网大会及具身智能综述文章披露，云迹科技的机器人智能体平台在某一峰值时点曾实现单日同时在线约3.6万台机器人，显示其服务机器人部署规模已达到数万台级别。 云迹科技自主研发的 UP 复合多态机器人被描述为具身智能重要途径之一：报道指出 UP 早晨可扮演送餐员、中午切换为清洁工、夜间承担巡逻员角色，在酒店、医疗、工厂、楼宇等多场景大规模落地，通过软件切换实现多角色服务。 [1][2][3][4][6][5][7]

从技术路径看，白皮书和综述将复合多态机器人视为“一机多态、多任务”的本体/形态路线代表。虽未详细说明其是否使用大模型或端到端控制，但结合具身智能发展报告中对 Alpha Bot 1S 等轮式复合机器人的描述，可以推断此类平台通常采用“复合本体＋分层控制＋部分大模型赋能”的架构：例如 Alpha Bot 1S 融合轮式底盘、折叠升降结构和高自由度机械臂，以仿人形态支持多任务切换，并在柔性多样场景中实现对任意物体的操作。 [1][2][3][4][6][5][7]

（四）服务机器人与数据平台公司：擎朗智能、云迹科技等 [1][2][3][4][6][5][7]

商用具身智能白皮书还提到擎朗智能和云迹科技等服务机器人公司在具身智能数据和产品规模部署上的作用。擎朗智能依托全栈自研技术体系及“研发—智造—供应链”能力，在配送、酒店、清洁、医疗和人形五大产品家族上构建服务机器人矩阵，服务餐饮、酒店、医疗、工厂、商超等多场景，报告称其约有10万台机器人服务约6万家全球客户，每日产生数亿条真实场景数据并进行数百次模型微调，用于支撑具身智能能力的持续演进。 这类公司虽然不一定在前沿端到端 VLA 或世界模型研究层面领先，但在数据采集和产品规模部署上对具身智能基础模型和控制路线提供了重要支撑。 [1][2][3][4][6][5][7]

云迹科技则通过其智能体平台和 UP 复合多态机器人，为具身智能提供多场景、多角色的数据与应用试验场，同时其大规模在线机器人数量展示了具身智能在服务场景中的规模化部署潜力。 [1][2][3][4][6][5][7]

（五）跨路线和公司维度的几点观察 [1][2][3][4][6][5][7]

综合上述公司矩阵，可以提炼出若干跨路线的现象：其一，海外人形与通用具身智能公司在融资规模和估值上整体领先，Figure AI、1X、Agility 等公司在 1.5–10亿美元级融资上占据重要位置，而国内银河通用、宇树科技等则在人民币数亿至十亿级轮次上快速追赶。 其二，国内通用具身终端公司（如智平方）和复合多态平台公司（如云迹科技）在端到端 VLA、大模型赋能和多场景部署上形成差异化布局，为具身智能基础模型提供应用试验场。 [1][2][3][4][6][5][7]

其三，从团队与能力结构看，行业报告反复强调三类技术背景团队的并存：传统硬件与运动控制团队在本体和控制侧具有优势，CV/自动驾驶团队在感知和场景理解上较强，大模型与强化学习团队在算法和数据利用方面更具前沿性，但往往需要补足机电工程和商业化能力。 这也意味着，不同公司在技术路线选择上与其团队基因高度耦合，端到端 VLA、大模型中心、分层控制和世界模型辅助路线在公司层面呈现出多样化组合。 [1][2][3][4][6][5][7]

需要强调的是，公开资料主要集中于少数头部和代表性企业，对许多中小公司以及国际范围内其他重要参与者的信息覆盖有限；同时，部分公司关于具体技术架构、数据比例、应用场景和团队构成的细节仅以宣传性语言披露而非完整技术报告。因此，本章对公司矩阵的整理更偏向“代表样本＋宏观趋势”，在公司维度的全面性和精细性上存在天然局限，后续比较和趋势分析应在这一前提下谨慎解读。 [1][2][3][4][6][5][7]

## 融资格局、团队背景与区域政策环境

具身智能作为新兴技术赛道，其产业发展高度依赖资本支持、团队能力结构和政策环境。商用具身智能白皮书、具身智能发展报告和赛道投资策略报告提供了相对系统的融资、团队和政策数据，为观察当前格局提供了基础。 [1][2][3][4][5][7]

（一）全球与中国具身智能融资概况 [1][2][3][4][5][7]

在全球范围内，机器人大模型报告统计了多家具身智能与人形机器人公司的重大融资事件：例如 Agility Robotics 在2022年4月完成约1.5亿美元 B 轮融资，估值约12.6亿美元；Figure AI 在2025年9月完成超过10亿美元的 C 轮融资，最新估值约390亿美元；1X Technologies 在2025年9月处于约10亿美元融资中的状态，估值约100亿美元；Skild AI、Physical Intelligence 在2024年间分别完成约3亿和4亿美元 A 轮融资；Apptronik 和 Field AI 则在2025年分别完成约3.5亿美元和3.14亿美元的 A 轮融资，估值分别约14.4亿美元和2亿美元。 这些数据表明，海外头部具身智能公司已进入十亿美元级融资和十亿至数百亿美元估值区间，资本市场对其长期潜力有较强预期。 [1][2][3][4][5][7]

中国市场方面，具身智能发展报告披露，截至2025年12月，我国具身智能和机器人领域投资事件数约为744起，融资总额约735.43亿元人民币。 机器人大模型报告进一步列出了多家代表性企业的融资情况：银河通用在2025年6月完成约11亿元人民币 Pre‑A 轮融资，最新估值约4.25亿美元；自变量在2025年9月完成约10亿元人民币 A+ 轮融资；星海图在2025年7月获得约1.22亿美元等值的天使+轮融资；宇树科技在2025年6月完成约7亿元人民币 C 轮融资；星动纪元和云深处分别在2025年7月完成约5亿元人民币的 A 轮和 C 轮融资。 这些数据反映出国内具身智能企业在人民币数亿至十亿级别融资上快速跟进，尽管绝对规模与部分海外头部公司仍存在差距。 [1][2][3][4][5][7]

国际投行和研究机构的宏观预测则进一步强化了资本逻辑：商用具身智能白皮书引用摩根士丹利和高盛等机构的观点指出，到2025年全球具身智能市场规模可能达到约192亿元人民币，未来五年复合增长率约73%，在十年左右时间内有望形成年万亿级人民币的市场需求。 报告同时给出了2025–2035年中国和全球具身智能市场规模及平均售价的增长曲线，显示国内市场规模从约21亿元人民币起步，预计在2035年增长至约2833亿元人民币，平均售价随时间下降。 中国信通院发展报告亦引用 Grand View Research 的预测，认为到2030年人形机器人市场约为40.4亿美元，L1–L3 自动驾驶汽车约1722亿美元，无人机约1636亿美元，三者合计约3398.4亿美元，表明具身智能所依托的相关产业市场空间巨大。 [1][2][3][4][5][7]

（二）代表公司融资与团队案例：智平方等 [1][2][3][4][5][7]

在具体公司层面，具身智能发展报告和官方新闻稿提供了智平方这一代表公司的较完整融资与团队信息。报告描述，智平方（深圳）科技有限公司成立于2023年4月，定位为 RoboService 公司，致力于研发生产通用智能具身终端，为各行业和家庭提供全场景、高可靠的通用智能机器人服务。 公司由郭彦东博士创立，他拥有美国普渡大学博士学位，师从美国工程院院士 Jan P. Allebach 和 Charles A. Bouman，在 AI 领域具有超过15年的学术研究和产业实践经验，被公司描述为“国家级创新领军人才”。 [1][2][3][4][5][7]

在融资方面，智平方在2025年1月宣布完成数亿元人民币 Pre‑A 轮战略融资，由达晨财智和敦鸿资产联合领投，基石资本跟投，此前投资方包括 SEE Fund、清智资本和国投创盈等机构。 报告称这是2025年具身智能领域首笔重大融资事件之一。在商业化进度上，智平方声称已与多家国内外一线车企、高端制造企业和互联网公司签约并获得大量商业订单，在2024年实现数千万元人民币确认收入，自我定位为国内最早进行通用智能机器人商业推广的公司之一。 [1][2][3][4][5][7]

在技术路径上，智平方与北京大学在2024年6月联合推出针对操作机器人的 RoboMamba 端到端具身大模型，官方表述称该模型早于 PI 的 OpenVLA 公开应用，并在未见任务泛化能力上显著优于 Google 的 RT 系列模型，相关成果入选 NeurIPS 2024，被公司定位为中国具身创业公司在 VLA 端到端方向的首次国际顶会发声。 这些资料显示，智平方在技术路线层面明确采用大模型＋端到端控制方案，在融资和营收层面也取得了初步突破，但公开资料尚未提供其客户分布、数据采集规模和具体控制架构的详细信息。 [1][2][3][4][5][7]

（三）团队背景与能力结构：三类技术基因 [1][2][3][4][5][7]

赛道投资策略报告和具身智能系统综述一致指出，当前具身智能和人形机器人创业与研发团队的技术基因可以大致划分为三类：一类是以传统硬件与运动控制为主的团队，具有强机电系统和控制能力；一类是以计算机视觉与自动驾驶技术为基础的团队，在感知和场景理解上具有优势；另一类则以大模型和强化学习为主，在算法和数据利用方面较为前沿。 报告指出，这三类团队在软件算法深度、机电工程能力和商业化经验等维度各有长短，构成了当前多样化的技术路线组合。 [1][2][3][4][5][7]

《基于大模型的具身智能系统综述》进一步将通用具身智能机器人的技术栈抽象为“大脑–小脑–本体”三层：本体层（机电结构与执行器）在机电和结构上相对成熟，但随着灵巧手等高自由度部件集成，自由度数量和对高速通信与算力的需求显著提高，成本成为关键约束；大脑层（具身基础大模型）截至2025年仍主要停留在实验室研发阶段，在模型数据规模与质量、训练方法、语言模型固有缺陷以及推理优化等方面存在未解决的科研问题。 在这一框架下，不同团队基因对应不同层级的优势：传统硬件团队擅长本体和“小脑”，CV/自动驾驶团队在感知与部分规划层较强，大模型/强化学习团队则在“大脑”层具有领先能力，但普遍需要在机电集成和商业化方面补课。 [1][2][3][4][5][7]

（四）政策环境与区域创新中心 [1][2][3][4][5][7]

在政策维度，商用具身智能白皮书和具身智能发展报告指出，自2023年以来，中国在国家层面密集出台多项支持具身智能与人形机器人的政策。其中包括：2023年2月工信部等发布的《“机器人+”应用行动实施方案》，推动机器人在重点行业的应用；2023年11月工信部发布《人形机器人创新发展指导意见》，将人形机器人明确为新增长引擎；2025年3月政府工作报告首次将“具身智能”列入国家未来产业重点培育清单；2025年4月，人形机器人技术要求系列国家标准获批立项。 [1][2][3][4][5][7]

在区域层面，白皮书和行业报告指出，北京、上海、杭州等城市在2024–2025年出台了多项具身智能和人形机器人产业专项规划与实施方案。例如，北京在2025年2月发布《北京具身智能科技创新与产业培育行动计划（2025—2027年）》，并与《北京市机器人产业创新发展行动方案（2023—2025年）》衔接；上海市政府办公厅在2025年8月印发《上海市具身智能产业发展实施方案》；杭州则发布《2024–2029年人形机器人产业规划》《杭州市加快建设人工智能创新高地实施方案》和《杭州市具身智能机器人“强链补链”三年行动方案（2025—2027年）》等。 具身智能发展报告还指出，自2023年中以来，中国已形成约两个国家级和五个省级人形机器人/具身智能创新中心，用于支持产业发展。 [1][2][3][4][5][7]

这些国家与地方政策通过明确具身智能的战略地位、设立创新中心和专项资金，以及推动标准制定，为具身智能技术路线提供了相对稳定的政策预期和试点场景。同时，世界互联网大会等机构也报道，2025年8月山东未来机器人等企业共同签署了被称为“全球首例万台具身智能机器人订单”的协议，订单量约一万台，被视为具身智能商业化加速的象征事件。 [1][2][3][4][5][7]

（五）产业经济性、回本周期与市场预期 [1][2][3][4][5][7]

在经济性维度，赛道投资策略报告指出，具身智能下游应用具有非标场景多、产品需大量二次开发等特点，几乎所有客户都会严格考察机器人采购后的回本周期是否能控制在约两年内。 报告基于两类主流复合机器人形态产品的 BOM 成本和量产规律估算，认为部分轮式复合机器人有望在2029年前后率先实现两年内回本的经济性目标。 这意味着，在当前阶段，大部分具身智能项目在 ROI 指标上仍处于验证期，经济性约束对技术路线选择和应用场景选择具有重要影响。 [1][2][3][4][5][7]

从市场预期看，商用具身智能白皮书给出的预测显示，2025–2035年中国具身智能市场规模将快速增长，平均售价则呈下降趋势，反映出规模化部署与成本下降的双重趋势。 中国信通院报告同时引用 Grand View Research 等机构的预测，认为人形机器人、自动驾驶车辆和无人机等相关市场到2030年合计规模约为3398.4亿美元，为具身智能提供了广阔的需求空间。 然而，两份报告也强调，当前通用具身智能商业化路线，无论采用端到端 VLA 还是分层“大模型＋控制器”方案，都普遍面临“感知–规划–控制–执行”闭环算法尚不成熟以及高质量具身数据严重匮乏的挑战，这些技术瓶颈构成了对产业规模化的关键约束。 [1][2][3][4][5][7]

（六）小结：资本、团队与政策的交织 [1][2][3][4][5][7]

综合以上证据，可以对当前具身智能产业的资本与人才格局做出若干观察：一是全球资本对具身智能的态度总体积极但分化明显，Figure AI、1X、Agility 等头部公司获得十亿美元级融资，而大量中小企业仍处于早期轮次；国内企业在数亿至十亿级别融资上表现活跃，但与海外部分头部公司相比仍有差距。 [1][2][3][4][5][7]

二是团队基因三分格局使得不同公司在“大脑–小脑–本体”三层技术栈上的能力分布各异，传统硬件、CV/自动驾驶和大模型/强化学习团队在软件、硬件和商业化维度的优势与短板互补，推动了多样化技术路线的探索。 [1][2][3][4][5][7]

三是政策环境在中国具身智能发展中扮演了重要放大器角色：国家层面通过将具身智能写入政府工作报告、出台“机器人+”行动和人形机器人指导意见等，将其上升为未来产业重点；地方政府通过创新中心、专项规划和订单引导，为企业提供了实验田和初期市场。 [1][2][3][4][5][7]

四是尽管资本、团队和政策共同推高了具身智能赛道的热度，但行业报告反复提醒，通用具身智能的商业化仍受到闭环算法不成熟和高质量数据匮乏的制约，在当前阶段更适合通过“找到具身智能的 L2 场景”（类似自动驾驶中的自动泊车）构建数据飞轮和杀手级应用，而非从一开始直接瞄准完全通用的 L5 场景。 [1][2][3][4][5][7]

总体而言，具身智能的资本与人才格局呈现出“头部集中、腰部活跃、长尾分散”的特征，政策环境在中国尤其积极，但技术与经济性双重约束意味着短期内产业化仍将围绕少数可控场景和具备明确回本路径的项目展开。 [1][2][3][4][5][7]

## 综合评估：产业阶段、竞争格局与未来趋势

基于前文技术路线与公司矩阵的整理，可以在已有公开证据范围内对具身智能产业阶段、竞争格局与未来趋势做出谨慎评估。整体来看，行业报告普遍认为，具身智能的发展历程可分为1950–2000年的哲学与概念提出期、2000–2020年的技术积累期，以及自2020年以来以大模型为核心驱动力的应用拓展期，目前全球正处于这一“大模型驱动应用扩展”的新拐点。 [1][2][3][4][5][6][7]

（一）产业阶段：从技术积累到大模型驱动的应用拓展 [1][2][3][4][5][6][7]

多份产业与学术报告一致指出，自2020年前后起，具身智能进入了以大模型驱动的应用扩展阶段：一方面，端到端 Transformer 控制模型（如 RT‑1 系列）在家庭厨房等限定环境下实现了约700个任务、约97% 平均成功率的表现，展示了大模型在具身控制中的潜力； 另一方面，以“大模型＋机器人”为核心的技术范式逐渐取代仅依赖传统模型或学习控制的阶段，大语言模型承担任务理解与代码生成，视觉语言模型负责环境语义理解，视觉语言动作模型负责端到端策略输出。 [1][2][3][4][5][6][7]

然而，具身智能发展报告与大模型综述也强调，截至2025年初，通用具身智能商业化仍处于“实验室向试点场景过渡”的阶段：端到端 VLA 系统尚未形成稳定的“感知–决策–执行”闭环，长程任务成功率通常仅在20%–40% 区间；同时，高质量闭环具身数据严重匮乏，空间泛化所需数据量与空间体积呈幂律关系，要在约38倍更大的空间范围内保持泛化，数据量需扩展约 38^0.35 倍，每增加一个数量级数据才能获得近似比例的性能提升。 这意味着，从宏观演进角度看，具身智能已经跨过纯技术探索期进入大模型驱动的应用拓展期，但从商业化成熟度看，仍处于有限场景试点与关键技术攻关阶段。 [1][2][3][4][5][6][7]

（二）竞争格局：路线多元与团队基因三分 [1][2][3][4][5][6][7]

在技术路线层面，学术与产业报告表明，当前具身智能竞争格局呈现多路线并行状态：端到端 VLA 路线以 RT‑1、RT‑2 等模型为代表，强调从多模态输入到动作的直接映射，在短程任务和单一平台上表现突出； 分层大模型路线通过 LLM/VLM 承担高层任务理解和技能调度，结合传统控制器或强化学习策略构建“大脑–小脑–本体”分层架构； 层级 LLM+RL 路线（如 Hi‑Core）通过 LLM 设高层策略、RL 生成低层动作，在长程、多步骤任务中更具结构优势； 世界模型与数据金字塔路线则从训练方法和数据侧为各类控制架构提供支撑。 [1][2][3][4][5][6][7]

在公司与团队维度，赛道投资策略报告和大模型综述将当前创业生态中的技术基因划分为三类：传统硬件与运动控制背景团队、计算机视觉与自动驾驶背景团队以及大模型与强化学习背景团队。 报告指出，这三类团队在软件算法、机电系统和商业化能力上各有长短：传统硬件团队擅长本体设计和控制，但在大模型与数据侧能力上相对欠缺；CV/自动驾驶团队在感知与场景理解上优势明显，但需补足本体和大模型能力；大模型/强化学习团队在算法和数据利用方面前沿，但往往需要引入本体工程和行业经验。 这一三分格局意味着不同公司在技术路线选择上与其团队基因高度耦合，这也是为何当前市场上既存在偏重端到端 VLA 的路线（如 RoboMamba 所代表的端到端模型），也存在更偏重分层控制和本体优化的路线。 [1][2][3][4][5][6][7]

（三）短中期趋势一：场景选择与“L2 级”杀手应用 [1][2][3][4][5][6][7]

赛道投资策略报告以自动驾驶为类比，指出相较于从一开始就直接开发和适配 L5 场景，具身智能更现实的路径是找到行业中的“L2 场景”（如自动驾驶中的自动泊车），以构建数据飞轮并形成杀手级应用。 报告同时强调，当前通用具身智能项目在下游应用中面对大量非标场景，需要大量二次开发，几乎所有客户都会严格考察机器人投资能否在约两年内回本；基于 BOM 和量产规律的推算认为，部分轮式复合机器人有望在2029年前后率先实现两年内回本的经济性目标。 [1][2][3][4][5][6][7]

结合宏观市场预测，商用具身智能白皮书给出的 2025–2035 年中国和全球市场规模与平均售价曲线显示，具身智能产品预计在未来十年内实现规模化部署并伴随价格下降。 然而，行业报告也反复强调，高质量闭环数据匮乏和“感知–规划–控制–执行”闭环算法不成熟是各路线共通的技术瓶颈。 因此，可以谨慎判断，在未来3–5年内，具身智能商业化将主要围绕若干“L2 级别”的场景展开，例如高度结构化的工厂、仓储、酒店和楼宇服务场景，而不是全面覆盖复杂家庭和开放城市环境。 [1][2][3][4][5][6][7]

（四）短中期趋势二：技术路线的阶段性共存与渐进收敛 [1][2][3][4][5][6][7]

在技术路线收敛问题上，学术与产业资料显示，至少在当前时间窗口内，端到端 VLA、分层大模型、层级 LLM+RL 和世界模型辅助路线将长期共存。 一方面，端到端 VLA 路线在短程任务和限定平台上已展示出高成功率样板（如 RT‑1），但在长程任务成功率和跨本体泛化方面仍存在约20%–40% 的局限； 另一方面，多时间尺度分层控制（LLM 设高层策略、RL/控制器生成低层动作）被视为解决高层 1–10 Hz 规划与低层 ≥100 Hz 控制之间协同问题的代表路径， 这在安全和稳定性要求高的工业与服务场景中更被工程实践所青睐。 [1][2][3][4][5][6][7]

世界模型和数据金字塔路线则以幂律数据规律为依据，从训练侧和仿真侧为各路线提供支持。例如，ManiBox 等实验表明，要在38倍更大的空间范围内实现相似泛化性能，数据量需按 38^0.35 倍扩展，每增加一个数量级的数据通常才能带来近似比例的性能提升， 这将驱动更多团队在世界模型和仿真平台上加大投入，以在可控成本下放大数据规模。 [1][2][3][4][5][6][7]

综上，可以推断未来3–5年具身智能技术路线将呈现“多路线共存＋局部收敛”的格局：在需要高安全性和可解释性的工业与服务场景中，分层大模型和层级 LLM+RL 路线可能成为主流；在数据资源充足且安全风险可控的实验和家用场景，端到端 VLA 路线将继续被验证和优化；世界模型与数据金字塔作为底层基础设施，将支撑各路线的训练和评估。 [1][2][3][4][5][6][7]

（五）区域与政策视角：政策高地与创新中心的长期作用 [1][2][3][4][5][6][7]

从区域政策角度，中国在具身智能赛道上的布局较为激进。具身智能发展报告和商用白皮书指出，2023年以来，国家层面通过“机器人+应用行动实施方案”、人形机器人创新发展指导意见、将具身智能写入政府工作报告以及人形机器人国家标准立项等举措，将具身智能和智能机器人明确为战略性未来产业； 北京、上海、杭州等城市则在2024–2025年发布具身智能和人形机器人产业规划及实施方案，并配套专项资金与创新中心。 [1][2][3][4][5][6][7]

这些政策使得中国在创新中心数量和资本投入上形成一定先发优势：截至2025年中，中国已建立约两个国家级和五个省级人形机器人/具身智能创新中心，用于支撑技术研发和试点应用； 同时，2025年8月山东未来机器人等企业签署的约一万台具身智能机器人订单，被媒体称为“全球首例万台订单”，被视为政策与产业协同推动具身智能商业化加速的信号。 [1][2][3][4][5][6][7]

从长期看，这种“政策高地＋创新中心”的模式有助于在标准制定、场景开放和资金支持方面为特定路线和公司提供优势，但也可能带来资源配置向少数头部企业集中的风险。行业报告提醒，尽管政策与资本共同推动赛道热度，但通用具身智能的核心仍在于深度感知、智能决策、泛化交互和灵巧执行等智能能力组合，人形外观本身并不是实现高智能和商业成功的充分条件，技术与商业评估需要回到闭环能力和回本周期等指标上。 [1][2][3][4][5][6][7]

（六）不确定性与风险：算法、数据与经济性三重约束 [1][2][3][4][5][6][7]

在未来趋势判断中，必须强调多重不确定性：第一，算法层面，端到端 VLA 和大模型中心路线在跨场景和跨本体泛化、长程任务成功率以及软硬协同方面仍存在显著短板，《具身智能发展报告》明确指出当前 VLA 系统在长程家务任务上的成功率多在20%–40%，难以支撑复杂真实环境的大规模应用。 第二，数据层面，高质量具身数据的获取成本极高，现有具身数据集规模远小于大规模视觉–语言数据（如 VIMA 约65万演示、RT‑1 约13万演示 vs LAION‑5B 的约57.5亿图文对）， 这使得具身基础模型在数据端面临长期瓶颈。 [1][2][3][4][5][6][7]

第三，经济性层面，行业报告强调非标场景多、二次开发重以及客户对两年内回本周期的刚性要求，使得大部分具身智能项目在短期内很难依靠单一场景实现稳定盈利，需要依赖复合多态机器人、多场景复用和规模化部署来摊薄成本； 同时，Diffusion‑VLA 类模型在训练和推理阶段需要 PFlops 级算力和大量显存（如 RT‑2 推理约需20GB 显存），为云端部署带来隐私与实时性问题，也限制了其在边缘设备上的直接部署。 [1][2][3][4][5][6][7]

综上，未来3–5年具身智能的现实图景很可能是：大模型＋机器人作为技术主线持续推进；端到端 VLA、分层大模型、层级 LLM+RL 和世界模型辅助多路线并行；政策与资本在部分区域形成“试验田”和标准高地；但在算法闭环、数据供给和经济性约束三重压力下，真正具备广泛泛化能力和稳健商业模式的通用具身智能系统仍需较长时间演进。现有证据支持对具身智能持“技术演进乐观、短期商业审慎”的综合判断。 [1][2][3][4][5][6][7]

## 信息不完备与研究局限说明

本报告在撰写过程中严格约束于若干公开综述与产业研究报告提供的证据，因此在公司覆盖范围、数据完整性和技术路线分类等方面存在显著不完备性和主观性。为便于读者合理使用结论，本章集中说明主要局限。 [3][2][1][7]

（一）数据来源范围与偏倚 [3][2][1][7]

首先，本报告的事实基础主要来自几类公开资料：一是学术综述文章，例如《基于大模型的具身智能系统综述》对“大脑–小脑–本体”技术栈、大模型赋能具身智能的系统结构以及具身数据稀缺性进行了系统梳理， 并指出本体技术整体相对成熟，但灵巧手等高自由度部件集成后自由度和通信、算力需求大幅提升，成本成为突出约束；与之相比，大脑层具身基础模型仍主要停留在“实验室”研发阶段，在数据、训练方法、语言模型固有缺陷与推理优化等方面存在大量未解决问题。 二是国家级与行业级发展报告，例如中国信通院的《具身智能发展报告》和券商研究机构发布的《机器人大模型深度报告》，提供了中国具身智能投资事件规模、全球与中国市场预测以及代表公司融资情况等数据； 三是产业白皮书和技术博客，如复合多态机器人白皮书和“大模型赋能的具身智能”综述，讨论了复合多态机器人方向、世界模型与合成数据、Diffusion‑Policy 与高精度仿真等技术。 [3][2][1][7]

这种资料来源结构天然带来几方面偏倚。其一，数据集中于中国政策环境、产业实践和若干海外头部公司的公开融资信息，对大量未披露或披露有限的中小企业缺乏覆盖。 其二，许多公司技术架构、数据路线、本体配置和团队构成的描述来自面向投资人或公众的宣传材料，上述报告多采用公司自述或公开新闻稿作为信息来源，缺少统一的技术审计和详细实验指标。 其三，部分前瞻性市场预测数据来自券商研究部门和国际投行研究，这些预测在方法、场景假设和宏观变量选择上并未在报告中充分展开，存在模型假设难以逐条验证的问题。 [3][2][1][7]

（二）公司矩阵、融资与团队信息的不完备 [3][2][1][7]

在公司维度，本报告仅选择了若干在公开报告中反复出现的具身智能代表企业进行技术路径与商业化进度的分析，例如 Figure AI、1X Technologies、Agility Robotics、Apptronik、Field AI 等海外人形和通用具身公司， 以及智平方、银河通用、宇树科技、自变量、星海图、星动纪元、云深处、云迹科技、擎朗智能等国内公司。 对这些公司融资轮次、金额与估值的数据完全依赖于《具身智能发展报告》和《机器人大模型深度报告》中整理的表格，例如 Figure AI 在2025年9月完成 C 轮融资、金额超过 10 亿美元、估值约 390 亿美元，1X Technologies 在相近时间段进行约 10 亿美元融资、估值约 100 亿美元，Agility Robotics 在2022年4月完成约 1.5 亿美元 B 轮融资、估值约 12.6 亿美元； 银河通用、宇树科技、自变量等公司在2025年中后期完成数亿至十亿元人民币不等的融资轮次。 [3][2][1][7]

这类数据存在几个局限。其一，报告中多未详细说明估值计算方法、是否包含二级市场价格或期权激励等要素，部分融资金额也使用“超×亿”“约×亿”等表述，存在不确定区间。 其二，除个别公司如智平方通过发展报告披露了更完整的团队背景（创始人为普渡大学博士、国家级创新领军人才，并拥有超过15年的AI学术研究与产业实践经历）和早期及 Pre‑A 融资机构信息， 大部分公司的团队结构、技术负责人履历与股权结构并未在底层资料中系统呈现。本报告因此无法对各公司组织能力与技术文化进行可靠比较，只能在有限证据下给出定性判断。其三，公司矩阵仅覆盖了在发展报告和深度报告中出现次数较多的企业，未系统纳入大量新创公司和传统机器人厂商在具身智能方向的探索，难以构成全球或全国范围的完整公司图谱。 [3][2][1][7]

（三）技术路线分类的主观性与映射问题 [3][2][1][7]

本报告采用的技术路线分类（模块化分层控制、分层大模型、端到端 VLA、层级 LLM+RL、世界模型辅助、数据金字塔、本体/形态路线等）是在若干中英文综述基础上进行统一和抽象的结果。学术综述如王文晟等系统采用“modular pipeline、world‑model‑based control、LLM for planning、policy learning from demonstration”等术语， 产业报告和政策文件则更偏向于“大脑–小脑–本体”技术栈及“人形机器人、复合多态机器人”等产品形态的分类。 在此基础上，本报告对不同来源的术语进行了映射和归纳，使其落在统一的路线框架下，这自然引入了抽象层面的主观性。 [3][2][1][7]

例如，将“LLM for planning”和部分“policy learning from demonstration”系统归入“分层大模型＋技能库”的路线，将“世界模型和视频世界模型用于仿真采样与 sim2real”归入“世界模型辅助路线”，将复合多态机器人视为“本体/形态路线”的重要分支， 这些归类都基于报告中的描述与图示，但并非所有原始来源都以相同方式定义边界。本报告在讨论各路线优劣时，可能弱化了某些模型在不同路线间的交叉属性，也未能覆盖所有存在于学术和产业实践中的细分路径。 [3][2][1][7]

此外，关于具身基础模型与具身大模型的构成，本报告主要依赖综述中对 ELM/EMLM、LLM、LVLM、MLM 和 VLA 等模型角色的描述， 在统一框架时也进行了简化。例如，将部分扩散策略类模型（Diffusion Policy、3D‑Diffusion 等）视为“动作生成模块”，并归入端到端或分层控制架构的子模块，而没有细分其在不同训练范式中的差异。这种简化便于宏观比较，但不适合用于微观架构层面的精确技术决策。 [3][2][1][7]

（四）时间窗口与预测的不确定性 [3][2][1][7]

本报告所引用的大部分证据发表于2024年下半年至2025年中后期：学术综述发表于2025年1月，具身智能发展报告的编制时间截至2025年12月， 机器人大模型深度报告在2025年8月发布， 技术博客和产业案例多发表于2025年下半年。 因此，本报告的结论严格限定在截至2025年底前的公开信息范围内，并不涵盖此后可能发生的技术突破、政策调整或新的融资事件。 [3][2][1][7]

特别是对于市场规模预测，深度报告引述摩根士丹利、高盛等机构的判断，认为2025年全球具身智能规模约为192亿元人民币，未来五年复合增长率约 73%，并在十年左右时间达到年万亿级市场需求；同时给出2025–2035年中国具身智能市场规模从约21亿人民币增长到约2833亿人民币的预测曲线。 这些数字依赖于宏观经济走势、政策持续性、技术突破进度和成本下降速度等多重假设，而原始报告并未在公开片段中详细展开模型设定。读者在使用这些预测时应注意其为情景分析而非确定事实，本报告也未对预测模型进行独立复现或压力测试。 [3][2][1][7]

（五）方法与结论的适用边界 [3][2][1][7]

方法层面，本报告采取“以公开综述和产业报告为主的文献综合”方式，而非基于原始数据的计量分析或实地调研；所有技术评价和产业判断均在原始报告结论的范围内进行延伸，并尽量保持与原文表述一致或仅做有限重组。 在这种方法下，报告可以对技术路线、大模型架构、本体发展和代表公司基本情况形成一定的系统化视图，但难以回答如下问题：某家公司不同产品线的真实部署规模和成本结构、各路线在具体子场景中的精确成功率和安全指标、各地区政策执行的实际效果，以及不同投资人与团队之间的竞争与合作细节等。 [3][2][1][7]

结论层面，行业综述与发展报告普遍认为具身智能是通往通用人工智能的重要路径之一， 并对“具身智能作为第七次科技浪潮主升浪”“全球资本不会缺席具身智能”等观点给出了论证。 同时，报告也强调当前具身智能商业化仍面临“感知–规划–控制–执行”闭环算法、数据规模与质量以及端到端大模型软硬协同等关键技术瓶颈， 主流产品智能水平普遍仅处于 L2 等级， 通往泛化智能仍有较长距离。这些判断本身在不同来源中已形成某种“专家共识”，但仍然是基于当前证据和研究者视角的阶段性结论。 [3][2][1][7]

因此，本报告在综合这些观点时采取“技术演进乐观、短期商业审慎”的态度，但必须强调：任何关于未来技术路线收敛方向、市场规模和竞争格局的讨论，均属于在有限证据上的理性推断，而非确定预测。读者在进行投资决策或政策设计时，应结合更多实时数据和独立调研，对报告中的定量数据进行交叉验证，并充分考虑具身智能技术和市场的高不确定性。 [3][2][1][7]
